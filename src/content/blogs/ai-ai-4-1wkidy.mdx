## 一、开篇：如果有个工具能替你做完这一步…

前端同事刚把设计稿交给 AI，让它照着出一版首页。结果出来一看：圆角统一 16px、阴影一层浅灰渐变、按钮全部蓝底白字、所有插图都像同一个 SaaS 模板的近亲。AI 不是没干活，而是它只懂一种"好看"——那种在训练集里出现频率最高、大家最容易接受的"安全款"。

这一篇，我把四个专门治"AI 味"的开源项目打包介绍给你。它们各自从不同角度，让 Claude Code、Cursor、Codex 这类编码 Agent 输出来的界面，少一点模板感，多一点人味儿。

## 三、项目解析

### Leonxlnx/taste-skill — 让 AI 拥有"品味"

Taste Skill 是一个便携式 Agent Skill，主打的就是 README 里那句话——"gives your AI good taste"。它不替换你的 Agent，而是给 Agent 喂一套关于排版、布局、动效、留白的成体系规则，从根上挡掉那些千篇一律的"AI 默认值"。装上之后，Agent 在写 JSX、CSS、布局的时候会被这些规则约束，不会再给你吐出那种一眼就能认出是 AI 生成的页面。

它还配套提供 **image-generation skills**，可以生成网页、移动端、品牌 kit 的参考画板，配合 ChatGPT Images 等图像生成工具先用，再用 Codex / Cursor / Claude Code 去落地实现，工作流是连贯的。MIT 协议，跟 Vercel Labs 的 agent-skills 体系兼容，安装和迁移成本都很低。

- **适合**：每天用 Cursor / Claude Code / Codex 写前端、又被"AI 味"折磨的设计师与工程师
- **不适合**：纯后端项目、或者完全不需要 UI 的命令行工具

**最小上手**

直接告诉 Agent：

```
帮我安装这个 skill：https://github.com/Leonxlnx/taste-skill
```

或者手动：

```
npx skills add Leonxlnx/taste-skill
```

装好后直接说：

```
帮我做一个现代风格的产品落地页，要有设计感，不要 AI 味
```

*开源地址：* **https://github.com/Leonxlnx/taste-skill**

### Nutlope/hallmark — 57 道闸门挡掉 AI 味

Hallmark 的定位更狠："a design skill that refuses to look AI-generated"。它的核心机制是**内置 57 个 slop-test 闸门**——也就是在 Agent 输出 HTML/CSS 之前，自动检测有没有落入"渐变英雄区 + 三栏特性 + 圆角按钮 + Emoji 装饰"这类 LLM 最常吐的套路。一旦触发就强制改稿，并跑一遍 pre-emit 自检。

它还内置了 **21 套主题**，从 Cobalt 的深蓝技术风、Lumen 的浅色现代风、到 Garden 的有机风、Carnival 的复古印刷感都覆盖。两个不同 brief 出来的页面结构完全不同，**不是同模板换色**。配套四个动词很实用：默认生成新 UI、`hallmark audit <target>` 审计现有代码、`hallmark redesign <target>` 推翻重构、`hallmark study <截图/URL>` 提取你欣赏的设计的 DNA 并输出可移植的 `design.md` 给其他 Agent 用。

- **适合**：希望 Agent 输出有"差异化设计"，而不是"安全款"的团队
- **不适合**：只想做后台管理系统、不在意视觉差异的项目

**最小上手**

直接告诉 Agent：

```
帮我安装这个 skill：https://github.com/Nutlope/hallmark
```

或者手动：

```
npx skills add Nutlope/hallmark
```

装好后直接说：

```
hallmark audit ./src/landing
```

*开源地址：* **https://github.com/Nutlope/hallmark**

### VoltAgent/awesome-design-md — 73 份品牌 DESIGN.md 直接抄

DESIGN.md 是 Google Stitch 提出的一个新概念——一个纯文本的设计系统文档，AI Agent 读 Markdown 就懂你的 UI 应该长什么样。**awesome-design-md** 收集了 **73 份真实网站的 DESIGN.md 复刻分析**，从 Claude 的暖橙编辑风、Cohere 的渐变数据感、ElevenLabs 的暗黑电影感，到 Mistral 的法式极简紫调都包含。

用法极简：挑一份顺眼的 DESIGN.md，复制到项目根目录，然后对你的 Agent 说"帮我做一个长得像这个的页面"，AI 就会照着里面的色板、字体、间距、组件规则去生成 UI。没有 Figma 导出、没有 JSON schema，**就是一份 Markdown**，跟 AGENTS.md 配合就是一套完整的"项目说明书"。如果你想要的小众品牌不在列表里，还可以去 [getdesign.md/request](https://getdesign.md/request) 申请定制。

- **适合**：明确想借鉴某个品牌设计语言、想要"立刻开工"的开发者
- **不适合**：想做完全原创、跟任何已有品牌都不一样的视觉

**最小上手**

挑一份喜欢的 DESIGN.md 下载到项目根：

```
curl -o DESIGN.md https://getdesign.md/claude/design-md
```

然后告诉 Agent：

```
按照 DESIGN.md 的规则，帮我重做一下首页
```

*开源地址：* **https://github.com/VoltAgent/awesome-design-md**

### nexu-io/open-design — 把编码 Agent 变成设计引擎

OpenDesign 是这一组里定位最"重"的一个：本地优先的桌面 App，macOS 和 Windows 都能跑。它的核心思路是把 Anthropic 那个 Claude Design 的"agent-native"工作流——读 brief、定方向、流式生成、自我 critique、交付——**完全开源**，变成你的本地工作室。

它能生成网页、桌面、移动端原型，实时仪表盘、PPT 演示文稿、图片、视频、Hype

rFrames 动效，输出格式覆盖 HTML、PDF、PPTX、MP4。底层支持 **DeepSeek Harness (`dsh`)、Claude Code、Codex、Cursor、OpenCode、Qwen、Copilot 等 26 种 CLI**，BYOK 接 OpenAI 兼容端点也支持。等于是把你电脑里已经装好的编码 Agent 全部接进设计流水线，配上品牌级的 `DESIGN.md` 设计系统、即用插件、沙箱 iframe 预览，构

成一个完整的设计→开发工作流。

- **适合**：需要"Agent 闭环产设计稿 + 代码"、并且要在本地跑、BYOK 控成本的团队
- **不适合**：只想装个 Skill 改改 CSS、不需要桌面 App 的人

**最小上手**

从 Release 页下载安装包：

```
https://github.com/nexu-io/open-design/releases
```

启动后用 BYOK 接上你的 Agent：

```
open-design connect --provider deepseek --key <your-api-key>
```

然后在 Home 里输入 brief：

```
帮

我做一个 SaaS 产品落地页，风格参考 Linear，深色主题
```

*开源地址：* **https://github.com/nexu-io/open-design**

## 四、总结与行动建议

四个项目都可以独立用，但侧重不同。**taste-skill 和 hallmark** 是门槛最低的 Skill，前者偏规则体系、后者偏主题库，先装一个就能立刻告别"AI 味"。**awesome-design-md** 适合你已经心里有具体品牌目标的情况，复制一份 DESIGN.md 进去最省事。**open-design** 是想要本地化、完整工作流、且不介意下桌面 App 的团队再上。

如果只挑一个，今天就从 `npx skills add Nutlope/hallmark` 开始；想要组合拳，就 taste-skill + awesome-design-md 一起装。
