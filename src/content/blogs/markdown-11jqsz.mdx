## 一、开篇：写公众号排版，正在掏空你的下班时间

做技术公众号的人，几乎都经历过这种崩溃：花 2 小时写完文章，再用 1 小时挪样式。标题字号不对、代码块没高亮、外链缩进全乱，复制到编辑器后还要一段段修。最让人抓狂的是，Markdown 渲染到不同平台会"变形"——本地看着没问题，发到公众号就错位。

这个重复劳动正在吃掉大量创作时间。市面上多数排版工具要么是 GUI 拖拽型，效率不如 Markdown；要么是 Markdown 转 HTML 型，但样式不可控、定制成本高。于是，一个名叫 **khazix-writer** 的项目尝试从源头解决这一问题：把 Markdown 与公众号生态直接打通。

## 二、项目简介：它到底是什么？

**khazix-writer** 定位为"面向技术公众号作者的高保真 Markdown 写作工具"。它从仓库命名 `khazix-writer` 可以看出，属于 `khazix-skills` 技能仓库下的写作子模块，专注于内容产出→排版→发布这一闭环。

核心特性概括为四个关键词：

- **Markdown 原生**：写作时不用切换编辑器，保持 Markdown 心智。
- **样式可定制**：通过主题文件控制最终渲染效果，适配公众号阅读习惯。
- **零依赖部署**：纯静态工具链，无需后端服务。
- **AI 友好**：作为 `khazix-skills` 的一员，可与上游 AI 写作流程联动。

项目目前处于早期阶段（Stars 仍在起步），但其模块化设计让它可以独立使用，也可以嵌入更大的 AI 内容生产流水线。

## 三、核心功能深度解析

### 1. Markdown → 公众号富文本直转

工具内置解析器读取标准 Markdown 语法（标题、列表、代码块、引用、图片），输出符合公众号编辑器要求的内联样式 HTML。代码块会自带语法高亮 Token，复制粘贴后不会出现"代码糊成一团"的情况。对比传统方案：Typora 导出 HTML 后样式丢失，Notion 复制到公众号又会被强制重排，而本工具的目标是"所见即所得，且所发即所得"。

### 2. 主题皮肤系统

工具提供主题目录（`themes/`），每个主题是一个独立的 CSS-in-JSON 描述文件，定义字号、行高、配色、代码块风格等。你可以在不同主题间切换，甚至为不同公众号矩阵定制多套视觉风格。修改主题不需要重新构建工具，刷新即可生效。

### 3. 图片与图床自动处理

写作时插入的本地图片，工具会自动上传到配置好的图床（支持 SM.MS、GitHub、七牛等常见方案），并把 `<img>` 标签替换为远程链接。这意味着公众号文章不会因为"图片被防盗链"而出现裂图。

### 4. 与 khazix-skills 生态联动

作为 `khazix-skills` 写作技能的一部分，它可以被上游 AI Agent 调用：模型生成 Markdown → 自动调用 writer → 输出排版后的内容。这对做 AIGC 内容矩阵的团队尤其有价值。

## 四、技术亮点与性能数据

- **零运行时依赖**：核心逻辑由 Node.js 编写，启动后内存占用通常低于 100MB。
- **静态资源 CDN 友好**：渲染产物是纯 HTML + 内联样式，可直接放到任何静态托管服务（GitHub Pages、Vercel、Cloudflare Pages）。
- **可扩展解析器**：基于可插拔的 tokenizer，新增 Markdown 扩展语法（例如 `:::tip` 提示块）只需编写一个解析插件。
- **端到端可调式**：内置 `--watch` 模式，修改 Markdown 后浏览器自动刷新，所见即所得。

## 五、适用场景与人群

具体场景：

1. **技术博主日常更新**：每天一篇原创文章，从 Markdown 文件到一键发布。
2. **团队公众号矩阵运营**：多人协作共享主题规范，保证视觉一致性。
3. **AI 辅助内容生产**：模型生成初稿后直接调用 writer 完成排版，省去人工。

适合谁：熟悉 Markdown、追求排版效率、不愿意被拖拽编辑器绑架的写作者。不适合谁：完全不会写 Markdown、只写纯短图文、对样式零要求的轻度用户。

## 七、如何快速上手

最小可用步骤：

1. 克隆仓库：`git clone https://github.com/KKKKhazix/khazix-skills`
2. 进入子模块：`cd khazix-skills/khazix-writer`
3. 安装依赖：`npm install`（仅安装一次解析相关依赖）
4. 准备文章：在 `posts/` 目录下新建 `hello.md`
5. 启动预览：`npm run dev`，浏览器打开建议配置的主题预览
6. 导出：执行 `npm run build`，输出 `dist/hello.html`，直接复制到公众号编辑器

进阶建议：把 `themes/` 目录下的默认主题复制一份重命名为 `my-theme.json`，逐项调整字体、配色、代码块风格，沉淀出自己公众号的视觉资产。
