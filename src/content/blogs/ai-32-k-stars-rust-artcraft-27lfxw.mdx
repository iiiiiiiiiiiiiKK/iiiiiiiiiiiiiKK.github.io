# ArtCraft：把"抽卡式"AI 生图，变成真正的视觉工程

## 一、开篇：别再手动折腾它了

凌晨改稿、反复输入"a girl, red dress, soft light, 8k, masterpiece"，结果模型给你吐出十张风格各异的脸——这种失控感，每一个用过 Midjourney 或 SD 工作流的人都懂。AI 生图最大的问题不是"画不好"，而是"画不准"：同一个角色换个角度就认不出，同一个场景换个机位就完全跑偏。

更让人抓狂的是工作流断层：PS 里抠图、Blender 里摆位、ComfyUI 里跑节点、剪映里合成——四五个软件来回切，单个镜头改一下构图就要全流程重跑。ArtCraft 想终结这种"拼接式创作"：把构图、角色、相机、3D 场景全部塞进同一个 IDE，让你先"搭景"再"生成"。

## 二、项目简介：一句话说明它是什么

ArtCraft 是 GitHub 上一个 32K Stars 的开源项目，定位为「艺术家专属的 AI 图像与视频创作 IDE」。它用 Rust 编写，主打"可视化精准控制"——你不再只靠文字 prompt，而是用 2D/3D 画布、角色摆姿、相机取景、3D Mesh 这些工程化手段来"施工"。核心关键词有三个：**可重复、模型中立、视觉可控**。

## 三、核心功能深度解析

### 1. Image to Location：让角色"住进"同一个房间

传统 AI 生图最大的坑是角色一致性。ArtCraft 的方案是：先放一张环境图，系统自动提取出可漫游的 3D 空间，你可以在里面拖动虚拟"演员"，从任意角度取景。同一栋楼、同一束光，连续镜头再也不用赌运气。

### 2. 2D + 3D 双轨图像合成

2D 模式下，你像用 Photoshop 一样叠图层、扣背景、加蒙版；3D 模式下，背景、前景、道具各自带深度信息，相机一动视差自动正确。两种模式可以混用——截一张图当贴图，丢进 3D 场景当道具。这就是 README 里说的"Mixed Asset Crafting"。

### 3. 角色摆姿与身份迁移

先用 Mannequin（默认模特）摆出你想要的姿势和构图，再指定一张角色参考图，模型会把这个姿势"贴"给目标角色。漫画作者和分镜师用这个功能，可以批量产出同一动作的不同角色版本，效率比传统 SaaS 工具提升明显。

### 4. 图生 3D Mesh

上传一张静态图，AI 直接生成可旋转、可打光的 3D 模型（Hunyuan 3D、Tripo3D 等 11 个模型可选）。电商产品图、游戏道具预览、影视概念设计都能用上，省掉一次 ZBrush 重建。

### 5. 统一 Prompt 与画布编辑

想偷懒？直接输入文字 prompt 走 Nano Banana Pro、GPT Image 2.5、FLUX 等 16 个图像模型。想精细？在画布上画蒙版、做局部重绘（inpainting）。同一个工作流里既有"快"也有"准"。

### 6. 模型中立：62 个模型统一调度

ArtCraft 内置完整的 62 模型目录，覆盖图像（16）、视频（25）、音乐音效（5）、3D 网格（11）、高斯泼溅世界（5）。Midjourney、Grok、Sora、World Labs Marble、Suno 全部可以一站式调用，模型不再被某个厂商锁死。

## 四、技术亮点与性能数据

- **Rust 原生性能**：核心引擎用 Rust 编写，桌面端启动快、内存占用可控，3D 视口帧率稳定。
- **多 Provider 抽象层**：所有模型走统一接口，新增一个模型只要写适配器，不必改 UI 层。
- **离线友好**：本地缓存资产与历史记录，重生成不需要重新上传整张图。
- **跨平台**：Windows、macOS 稳定版可直接下载，Linux 用户可从源码构建。
- **双协议开源**：MIT 与 Apache-2.0 双授权，商业使用无版权风险。

## 五、适用场景与人群

**适合谁**：
- 分镜师与影视概念设计师，需要跨镜头保持角色与场景一致；
- 电商与游戏美术，想快速产出多角度产品图或 3D 道具预览；
- 漫画作者与插画师，需要批量产出同姿势不同角色；
- AI 工作流研究者，想在一个 GUI 里横向对比 60+ 个模型效果。

**不适合谁**：
- 只想一键出图、不关心构图控制的纯文字 prompt 用户；
- 追求手机端随手画的轻量创作者（目前仅桌面端）；
- 需要本地跑 Stable Diffusion 私炉模型、对云端 API 零信任的硬核自托管玩家。

## 七、如何快速上手

1. **下载安装**：访问 [getartcraft.com](https://getartcraft.com/) 下载 Windows/macOS 稳定版；追求最新功能去 GitHub Releases 页面。
2. **注册账号**：首次启动需登录 ArtCraft 云服务（用于调度各 Provider API）。
3. **最小可用流程**：新建项目 → 拖入一张背景图 → 用 "Image to Location" 生成 3D 空间 → 拖入角色参考图 → 在 3D 视口里摆位取景 → 点击生成。
4. **进阶玩法**：接入自有 API Key、组合 2D 蒙版与 3D Mesh、用 Kitbashing 拼接资产库搭复杂场景。
5. **从源码构建**：Linux 用户参考仓库内 `_docs/dev_setup.md`，需要 Rust 1.75+ 与 Node 环境。

## 八、总结与行动建议

ArtCraft 解决了一个被讨论得太久但落地太少的痛点：**AI 生图的"工程化"**。它把 2D 合成、3D 场景、角色摆姿、相机控制这些传统美术流程压缩进同一个 Rust 驱动的 IDE，再把 60+ 个顶尖模型装进同一个目录。对于任何严肃的视觉创作者，这种"先搭景、再生成"的工作流，比纯文字 prompt 稳定得多。

**行动建议**：先用一个 5 分钟的 "Image to Location" 测试体验角色一致性，再决定要不要把它接入你的正式工作流。
