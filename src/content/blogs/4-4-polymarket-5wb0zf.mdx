## 一、开篇：为什么你需要这个工具？

预测市场正在爆发。Polymarket 上每日交易额突破千万美元,无数交易者盯盘到凌晨,只为抢到一次套利窗口。问题在于:15 分钟加密市场的瞬间暴跌套利,需要毫秒级响应;聪明钱的跟单,需要 7×24 小时不离线;套利机会的出现,通常只持续几秒钟。

人类根本无法胜任这套工作,但一个开源交易机器人可以。本文介绍的项目 Polymarket-bot,GitHub 已收获 434 Stars,TypeScript 编写,主打「4 策略合一」,并在新版本中加入了工业级风控体系,直击预测市场交易者最焦虑的两个痛点:机会抓不住、本金守不住。

## 二、项目简介:一句话说明它是什么

Polymarket-bot 是一个面向 Polymarket 预测市场的开源自动化交易机器人,集成 4 套核心策略(套利 / 暴跌套利 / 跟单聪明钱 / 直交易),并配备可视化 Dashboard。最新 v3.1 版本重写了风控模块,引入 4 层资金保护机制与动态仓位管理,从「能跑」升级到「能长期跑」。

关键里程碑:

- GitHub Stars:434
- 主语言:TypeScript
- 最新版本:v3.1(2026 年 1 月)
- 作者:@Mr_CryptoYT

## 三、核心功能深度解析

### 1. ⚖️ 套利策略(Arbitrage)

策略原理简单粗暴:在 Polymarket 同一市场中,如果 `YES 价格 + NO 价格 < 1.00 美元`,机器人会立刻双边买入,等待市场结算时获得价差利润。v3.1 把最低利润阈值从 0.5% 抬到 1%,专门覆盖 Polygon 链上的 Gas 费用,避免「赚了 Gas 钱倒贴」的尴尬。这套策略风险极低,适合作为机器人收益的稳定基本盘。

### 2. 📉 暴跌套利(DipArb)

专门针对 15 分钟加密市场(BTC、ETH)的极端行情:当价格在 3 秒内暴跌超过 15% 时,机器人立刻买入暴跌一侧(Leg 1),再对冲买入另一侧(Leg 2)。无论市场最终走向哪边,两腿组合都能锁定收益。v3.1 新增的「最低 $1.50 仓位」约束,确保所有仓位都能正常平仓,杜绝「卡住出不来」的隐患。

### 3. 🐋 聪明钱跟单(Smart Money)

机器人自动扫描 Polymarket 排行榜上的高胜率交易者,并复制他们的操作。v3.1 显著抬高了筛选门槛:

- 胜率 ≥ 60%(原 50%)
- 总盈利 ≥ $500(原 $100)
- 盈亏比 ≥ 1.5x
- 一致性评分 ≥ 70%
- 单笔交易盈利占比 ≤ 30%(过滤「靠运气一把梭」的鲸鱼)

这套筛选让被跟单的目标从「赚过钱的人」变成「持续能赚钱的人」。

### 4. ⚡ 直交易工具(Direct Trading)

给手动党准备的「超能力工具箱」,包含 FOK(Fill or Kill,要么全成否则全撤)、Sniper(略高于市价的快速扫货)等快捷工具。v3.1 新增了 15% 止损、25% 止盈、7 天最长持仓时间,补齐了手动交易最容易踩的「忘了卖」短板。

## 四、技术亮点与性能数据

v3.1 的核心升级全部围绕「资金安全」展开,体现在以下三个维度:

1. 4 层风控体系
   - 第 1 层:日内亏损 5% 暂停 60 分钟
   - 第 2 层:30 天亏损 15% 暂停到月底
   - 第 3 层:回撤 25% 暂停 7 天
   - 第 4 层:累计亏损 40% 永久停机

2. 动态仓位算法
   - 基础仓位从 3% 降到 2%
   - 连亏时每笔再减 20%(3 连亏后单笔降至 $3.20)
   - 连胜时每笔加 10%,上限 5%(5 连盈后单笔 $7)

3. 工程细节
   - Polygon 链上 Gas 费单独核算
   - 浏览器 Dashboard 实时显示 PnL 与风控状态
   - 一键切换 Dry Run / Live 模式
   - Emergency Stop + Panic Sell 双保险

生态方面,项目对 MetaMask、Polymarket 代理钱包均兼容,部署只需 Node.js 18+,Windows / macOS / Linux 全平台支持。

## 七、如何快速上手

### 最小部署步骤

1. 克隆仓库

   `git clone https://github.com/MrFadiAi/Polymarket-bot.git && cd Polymarket-bot`

2. 安装依赖并构建 Dashboard

   `npm install && cd dashboard && npm install && npm run build && cd ..`

3. 复制 `.env.example` 为 `.env`,填入 MetaMask 导出的 `POLYMARKET_PRIVATE_KEY`,设置 `CAPITAL_USD=50`、`DRY_RUN=true`

4. 启动机器人

   `npx tsx bot-with-dashboard.ts`

5. 浏览器打开 `http://localhost:3001`,即可看到 Dashboard

### 进阶建议

- 先 Dry Run 跑 24-48 小时,观察策略触发频率
- 第 3-9 天切到 Live 但仍用 $50 小资金验证
- 第 10 天起,根据收益曲线逐步放大到 $250+
- 始终保留 1-5 美元 MATIC 用于 Gas 费
- 钱包私钥千万不要提交到 GitHub 或截图分享
