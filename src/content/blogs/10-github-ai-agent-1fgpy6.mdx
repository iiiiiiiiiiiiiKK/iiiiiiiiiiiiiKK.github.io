## 三、项目解析

### 01 ｜ vectorize-io/hindsight — 让 Agent 真正「记住并学习」

**Hindsight 是为 Agent 而生的长期记忆系统**，目标不是「召回对话历史」，而是让 Agent 在使用过程中不断学习。它绕开了 RAG 和知识图谱的常见短板，在 LongMemEval 基准上拿了 SOTA，性能由 Virginia Tech 和华盛顿邮报独立复现。**核心能力是「retain / recall / reflect」三段式**：保留事实、召回相关、反思归纳，并支持按 memory bank 隔离。

- 技术亮点：原生集成 25+ LLM 提供商；提供 Python 嵌入式模式，无需起服务；Docker 一行启动（端口 `8888` 是 API，`9999` 是 UI）。
- 适合谁：用 Codex/Claude Code 搭长周期助手的开发者；想给 Agent 加上「跨会话记忆」的小团队。
- 不适合谁：只想做一次性问答、不需要长期上下文的场景。

**最小上手**

直接告诉 Agent：

```
帮我安装这个 skill：https://github.com/vectorize-io/hindsight
```

或者手动安装 docs skill：

```bash
npx skills add https://github.com/vectorize-io/hindsight --skill hindsight-docs
```

装好后对 Agent 说「记住我偏好用 TypeScript」，下次再问就直接复用上下文。

*开源地址：* **https://github.com/vectorize-io/hindsight**

### 02 ｜ stablyai/orca — 并行跑一群编程 Agent 的桌面编排器

**Orca 是一台「Agent 母舰」**，专门解决「我同时开了 N 个 Codex 窗口却分不清谁在干嘛」的问题。它能把 Codex、Claude Code、OpenCode、Pi 并行跑在各自隔离的 git worktree 里，从一个面板集中跟踪。**核心能力是「并行 worktree + 终端分屏 + 移动端遥控」**：一个提示词扇出到五个 Agent、各自独立分支、最后合并胜者；手机端能收到完成通知并继续发指令。

- 技术亮点：WebGL 渲染的终端，支持无限分屏和滚动回放；Design Mode 可点击真实 Chromium 页面元素，把 HTML/CSS/截图直接喂给 Agent；SSH worktree 支持远端大机器跑任务并自动重连。
- 适合谁：高频用 AI 写代码、要对比多方案输出的资深工程师；管理多个并行任务的 Tech Lead。
- 不适合谁：只用 ChatGPT 网页版聊聊、不跑本地 Agent 的轻度用户。

**最小上手**

去官网下载桌面端：

```
https://www.onorca.dev/download
```

装好后把已有的 Codex/Claude Code 目录拖进去，输入一条提示词，Orca 自动派给多个 Agent 跑在不同 worktree，跑完直接在面板里对比 diff。

*开源地址：* **https://github.com/stablyai/orca**

### 03 ｜ cloudflare/security-audit-skill — 六阶段结构化安全审计

**这是 Cloudflare 内部漏洞发现平台的单仓库起点**，把一次安全审计拆成六个阶段：侦察 → 覆盖驱动狩猎 → 候选验证 → 结构化输出 → 独立记录复核 → 目标中立报告。每一阶段都有独立的 Agent 接力，`findings.json` 用 JSON Schema 校验，最终报告由覆盖账本反推生成。**核心能力是「覆盖账本 + 三种裁定」**：`confirmed`（带完整源码溯源）、`needs_validation`（未解事实，无严重等级）、`rejected`（已证伪）。

- 技术亮点：自带零依赖校验器 `validate-findings.cjs` / `validate-coverage-ledger.cjs`；多次跑同一仓库是「叠加式」的，会复用已有账本填补空白；提供 12 类专项狩猎提示（Web 协议、客户端、供应链、云部署等）。
- 适合谁：维护中型以上代码库、需要在 PR 阶段做安全审计的团队；做漏洞研究的独立研究员。
- 不适合谁：只想要一个简单 linter、不需要结构化报告的个人项目。

**最小上手**

直接告诉 Agent：

```
帮我安装这个 skill：https://github.com/cloudflare/security-audit-skill
```

或者手动：

```bash
npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit
```

装好后在你审计的代码库目录下打开 Agent，说：

```
security audit this codebase
```

Agent 会按六阶段自动跑，结束后给你 `REPORT.md` 和结构化的 `findings.json`。

*开源地址：* **https://github.com/cloudflare/security-audit-skill**

### 04 ｜ affaan-m/ECC — Agent Harness 性能优化系统

**ECC 把「资深工程师怎么做」打包成 Agent 能照搬的技能 + 本能 + 记忆 + 安全护栏**，定位是 Agent Harness 的「操作系统」。它跨 Claude Code、Codex、OpenCode、Cursor 等多种 IDE，覆盖从规划、编码、测试到安全审计的完整工作流。**核心能力是「本能（instincts）+ 技能（skills）+ 记忆（memory）」三层**：底层是自动触发的小习惯，中间是可调用的工作流，顶层是跨会话的上下文。

- 技术亮点：提供 `ecc-universal` 和 `ecc-agentshield` 两个 npm 包；GitHub App 一键安装；支持 Bash/TypeScript/Python/Go/Java/Perl/Markdown 七类语言的脚手架。==注意：必须从官方仓库、官方 npm 包或 GitHub App 安装，第三方镜像可能含恶意代码==
- 适合谁：每天重度依赖 AI 写代码、想把工作流沉淀下来的全栈工程师；做 AI IDE 集成的团队。
- 不适合谁：只偶尔让 AI 补个函数、不需要记忆和习惯的轻度用户。

**最小上手**

Claude Code 用户最省事：

```
/plugin marketplace add affaan-m/ecc
/plugin install ecc@ecc
```

或者一行命令装全套：

```bash
npx skills add affaan-m/ecc
```

装好之后 Agent 会自动在合适时机调用本能和技能。

*开源地址：* **https://github.com/affaan-m/ECC**

### 05 ｜ paperclipai/paperclip — 像管理公司一样管理 Agent 团队

**Paperclip 把 Agent 协作抽象成「公司管理」**：CEO、CTO、工程师、设计师、市场——每个角色都是一个 Agent，用目标（goal）而非 PR 驱动它们干活。**核心能力是「四大支柱」**：任务管理（带审批门）、组织架构、训练循环、基础设施，从单一仪表盘监控成本、预算和工作进度。

- 技术亮点：Node.js + React 全栈；兼容任何「能接收心跳」的 Agent（OpenClaw、Codex、Claude Code、Cursor、Bash、HTTP）；支持 24/7 自主运行但保留人工介入通道；可用手机端看仪表盘。
- 适合谁：同时开着 20+ 个 Claude Code 终端、需要统筹的 Tech Lead；想把多个不同 Agent 组成「虚拟公司」的创业者。
- 不适合谁：单兵作战、只用一两个 Agent 的独立开发者。

**最小上手**

最简启动：

```bash
git clone https://github.com/paperclipai/paperclip
cd paperclip && npm install && npm run dev
```

跑起来后在 UI 里定义一个目标（比如「搭建一个 AI 笔记应用冲到 $1M MRR」），再挑几个 Agent 角色上线，仪表盘会自动分配任务。

*开源地址：* **https://github.com/paperclipai/paperclip**

### 06 ｜ dream-num/univer — 一套 SDK 搞定表格、文档、幻灯片

**Univer 是面向 AI Agent 的 Office Harness**，把表格、文档、幻灯片、Canvas、关系表、PDF 装进同一个运行时。**核心能力是「插件化 + Canvas 渲染 + 公式引擎 + Facade API」**：要什么功能就装什么插件，从 SaaS 嵌入式编辑到服务端 Node.js 处理用同一套架构。

- 技术亮点：Canvas 渲染保证 10K+ 单元格的流畅度；Facade API 浏览器和 Node.js 通用；单元格和图表、控件可双向绑定，适合搭仪表盘；同源产品 Univer Workspace 是完整的参考实现。
- 适合谁：要在自家产品里嵌入 Office 类编辑能力的 SaaS 团队；做 BI/报表/AI 应用的工程师。
- 不适合谁：只是想本地打开 Excel 文件、已经有 Office 365 的用户。

**最小上手**

浏览器里快速体验：

```bash
npm install @univerjs/presets @univerjs/preset-sheets-core
```

```javascript
import { createUniver } from '@univerjs/presets';
import '@univerjs/preset-sheets-core/lib/index.css';

const univer = createUniver({ theme: 'default' });
univer.createUniverSheet({});
```

跑起来就是一个嵌入网页的电子表格，可以继续装 `@univerjs/preset-docs-core` 加文档能力。

*开源地址：* **https://github.com/dream-num/univer**

### 07 ｜ alibaba/open-code-review — 阿里内部孵化的精准代码审查

**Open Code Review 是阿里集团内部用了两年的官方 AI 审查工具**，基于 Git diff + LLM Agent 做行级精准评论。它会读完整文件、搜索代码库、参考其他变更文件，给出深度评审而非表面 diff 反馈。**核心能力是「确定性流水线 + LLM Agent 混合架构」**：内置 NPE、线程安全、XSS、SQL 注入等多语言规则集，支持 OpenAI / Anthropic 兼容接口。

- 技术亮点：AACR-Bench 基准显示，同模型下 Precision 和 F1 显著高于通用 Agent，**token 消耗仅约 1/9**；支持 `ocr scan` 模式对全文件审计（适合陌生代码库）；同时支持 Claude Code / Codex / Cursor / Kimi Code。
- 适合谁：中大型团队的代码审查流水线；追求高信噪比、不想被 AI 噪声淹没的工程师。
- 不适合谁：纯个人小项目、偶尔 review 一次的场景。

**最小上手**

全局安装 CLI：

```bash
npm install -g @alibaba-group/open-code-review
```

对当前 PR 做审查：

```bash
export OPENAI_API_KEY=sk-xxx
ocr review --base main --head feat/new-api
```

结果会写到 `findings.json`，带行号和严重等级。

*开源地址：* **https://github.com/alibaba/open-code-review**

### 08 ｜ Tencent/WeKnora — 把企业文档变成可推理的知识库

**WeKnora 把团队的文档、Wiki、数据源统一收口**，提供三种使用方式：RAG 直接问答、Agent 多步任务、Wiki 自维护知识组织。**核心能力是「同源知识库 + 三种消费模式」**：一份知识既能查、又能推理、还能组织成 Wiki，三者共享检索和索引。

- 技术亮点：支持飞书/Confluence/Notion/语雀/GitLab 等自动同步；解析 PDF/Word/图片/Excel/XMind 等 10+ 格式；Agent 跑在 Docker/E2B/Cube 沙箱里，可通过浏览器扩展操作用户自己的 Chrome/Edge；支持跨会话长期记忆和检索片段回滚。
- 适合谁：要做企业内部知识问答、合规检索、Wiki 自动维护的团队；想让 Agent 接管多步文档任务的运维。
- 不适合谁：只有几个文档、装个 ChatPDF 就能解决的轻度需求。

**最小上手**

Docker 一键起：

```bash
git clone https://github.com/Tencent/WeKnora
cd WeKnora
docker compose up -d
```

浏览器访问 `http://localhost:3000`，上传 PDF/Word/飞书链接，切换 RAG/Agent/Wiki 三种模式试用。

*开源地址：* **https://github.com/Tencent/WeKnora**

### 09 ｜ anthropics/financial-services — 投行/PE/财富管理场景的 Claude 模板

**这是 Anthropic 官方开源的金融服务 Agent 集合**，覆盖投行、股票研究、PE、财富管理四大场景。每个 Agent 都同时提供两种形态：Cowork 插件（开箱即用）和 Managed Agents API 模板（私有部署）。**核心能力是「自包含 Agent + 垂直技能包」**：装一个 Agent 等于装了一整套相关技能和 MCP 连接器。

- 技术亮点：内置 Pitch Agent（comps/precedents/LBO 一键出 pitch deck）、Market Researcher、Earnings Reviewer、Model Builder、GL Reconciler 等 10 个 Agent；支持 `/comps`、`/dcf`、`/earnings` 等斜杠命令；明确分离「人类签署」环节，所有输出待审。==注意：所有产出仅为草稿，最终须由持牌专业人士签署==
- 适合谁：金融服务行业的分析师、基金运营、合规岗；想用 AI 起草尽调材料、模型、研报的团队。
- 不适合谁：非金融场景；个人投资者想直接拿结果做决策。

**最小上手**

Cowork 端最简单——在插件市场粘贴仓库 URL：

```
https://github.com/anthropics/financial-services
```

Claude Code 端：

```bash
claude plugin marketplace add anthropics/financial-services
claude plugin install pitch-agent@claude-for-financial-services
claude plugin install market-researcher@claude-for-financial-services
```

装好后用 `/comps` 跑可比公司分析、`/dcf` 跑 DCF 模型。

*开源地址：* **https://github.com/anthropics/financial-services**

### 10 ｜ addyosmani/agent-skills — 资深工程师流程封装成的 25 个技能

**Addy Osmani 把资深工程师的开发流程打包成 9 个斜杠命令和 25 个技能**，覆盖 Define→Plan→Build→Verify→Review→Ship 全周期。每个技能都内嵌质量门和最佳实践，Agent 在合适时机自动激活。**核心能力是「生命周期斜杠命令 + 按需激活技能」**：`/spec` 先写规范，`/plan` 拆任务，`/build` 增量实现，`/test` 证明有效，`/review` 守质量门，`/ship` 安全发布。

- 技术亮点：支持 `/build auto` 模式，审批一次后全自动跑完所有任务；技能按场景自动激活（设计 API 触发 `api-and-interface-design`，做 UI 触发 `frontend-ui-engineering`）；通过 skills CLI 一行命令装到 70+ Agent（Claude Code、Cursor、Codex、Copilot、Cline 等）。
- 适合谁：所有重度用 AI 写代码、希望流程标准化的开发者；想给团队立统一工程规范的 Tech Lead。
- 不适合谁：只在 ChatGPT 网页版补一行代码的极轻度用户。

**最小上手**

任何 Agent 一键装全套：

```bash
npx skills add addyosmani/agent-skills
```

或者挑一个技能先试试：

```bash
npx skills add addyosmani/agent-skills --skill code-review-and-quality
```

装好后用 `/spec` 启动一次完整流程：先写需求、再拆任务、再写代码、再测试、再 review、再发布。

*开源地址：* **https://github.com/addyosmani/agent-skills**
