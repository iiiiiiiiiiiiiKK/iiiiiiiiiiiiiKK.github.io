## 一、开篇：为什么你需要这个工具？

深夜打开直播间，你看到 Neuro-sama 边玩《我的世界》边和弹幕互动，反应快、段子多、还能一边建造红石机器。但下播之后，这位「数字生命」就消失了——因为她不开源，你无法把她请回家。

更尴尬的是，市面上主流的 AI 陪聊工具（Character.ai、JanitorAI、SillyTavern）只能聊天，Character.ai 月活过亿却做不了「游戏陪玩」；大多数开源 AI VTuber 又卡在本地部署、GPU 依赖、跨平台兼容性上，普通玩家很难跑起来。

截至 2026 年 3 月，GitHub 上 47,766 颗 Star 的 Project AIRI 给出了答案：一个真正属于你自己的、可运行在浏览器和桌面端的、能陪你打游戏和实时语音的 AI 数字伙伴。

## 二、项目简介：一句话说明它是什么

**Project AIRI** 是一款自托管、用户拥有的 AI 伴侣平台，灵感来自 Neuro-sama，定位为「赛博生命的灵魂容器」。核心特性包括：实时语音聊天、可玩 Minecraft 与 Factorio、跨平台支持 Web/macOS/Windows/Linux/iOS/Android。最新版本 v0.10.2 已发布，配套 23+ 个 LLM 服务商与 5 种 TTS 引擎。

## 三、核心功能深度解析

### 1. 实时语音聊天：端到端音频管线

AIRI 内置「耳朵 + 嘴巴」完整链路：浏览器端麦克风采集 + 客户端语音识别（VAD 说话检测） + LLM 推理 + 多供应商 TTS 合成。它自研的 `unspeech` 代理把 ElevenLabs、Azure、OpenAI 兼容接口、阿里云、Local Kokoro 统一为标准 OpenAI 格式，切换 TTS 不用改业务代码。

### 2. AI 游戏陪玩：不止于聊天

这是 AIRI 最杀的功能——AI 直接下场打游戏。Minecraft 通过 Mineflayer 协议操控服务端，Factorio 通过 RCON API 调度 `autorio` 自动化库，Kerbal Space Program 也在路线图上。Electron 桌面版默认调用 NVIDIA CUDA 与 Apple Metal 加速，浏览器版用 WebGPU/WebAssembly 兜底。

### 3. 跨端 Stage 舞台：浏览器也是她的身体

AIRI 把 Live2D 与 VRM 角色模型整合进 Stage：自动眨眼、视线追踪、待机眼神漂移全部内置，同一套代码跑在 Web、Electron、Capacitor（PWA/iOS/Android）上。开发者用 Vue 3 + TypeScript 扩展即可，零平台分支。

### 4. 全本地数据层：DuckDB-WASM + pgvector

记忆系统选用 `@proj-airi/duckdb-wasm`：在浏览器里跑 DuckDB 数据仓库；规划中的 Memory Alaya 将接入 pgvector 做长期记忆与 RAG。这意味着即使你拔掉网线，AI 也能回忆你们聊过什么。

## 四、技术亮点与性能数据

- **Web 技术栈原生**：WebGPU、WebAudio、Web Workers、WebAssembly、WebSocket 从 Day 1 接入，桌面端走 CUDA/Metal 兜底，避免「Web 慢」的刻板印象。
- **23+ LLM 服务商**：OpenAI、Claude、Gemini、DeepSeek、Qwen、Ollama、vLLM 全部开箱即用，统一直连层 `xsai` 仅 6KB。
- **i18n 覆盖**：简体中文、英文、日文、俄文、越南文、法文、韩文 7 种语言，走 Crowdin 协作翻译。
- **生态矩阵**：12+ 子项目已孵化，含 `xsai-transformers`、`mcp-launcher`、`@proj-airi/drizzle-duckdb-wasm` 等。

## 五、适用场景与人群

- **直播主与 VTuber 爱好者**：想要一个 7×24 陪你播、不会下播的 AI 副驾驶。
- **独立游戏玩家**：让 AI 替你跑图、挖矿、搭流水线，Factorio 自动化研究必备。
- **二次元内容创作者**：Live2D/VRM 角色直接接入，想自己造一个「绊爱」或「Neuro-sama」。
- **AI 应用开发者**：想研究 LLM Agent、记忆系统、跨端架构的工程师。

不适合：纯聊天党（Character.ai 体验更轻）、商业客服系统（项目仍处早期，定位偏娱乐）。

## 七、如何快速上手

桌面端最快路径（Windows）：

```powershell
winget install MoeruAI.AIRI
```

macOS 用户：

```bash
brew install --cask airi
```

Linux/NixOS 用户：

```bash
nix run github:moeru-ai/airi
```

开发者从源码启动：

```bash
pnpm i
pnpm dev            # 浏览器 Stage
pnpm dev:tamagotchi # 桌面端 Electron
pnpm dev:pocket:ios # iOS 移动端
```

配置 LLM Key（任选其一）后即可激活角色。官方 Discord 有 1.3 万+ 成员答疑。
