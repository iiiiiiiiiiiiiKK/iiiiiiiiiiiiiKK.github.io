# CS Board：上传一段声音、一份文案，它就能还你一支会说话的白板动画

## 一、开篇：你还在为这件事头疼吗？

做一条 60 秒的口播视频，传统流程要写脚本、找配音、画分镜、做动效、校字幕，至少折腾大半天。如果你想要的不是真人出镜的 Vlog，而是一支干净的白板讲解视频——从零开始画的那种——工作量还要再翻一倍。AI 时代看似有一堆工具能帮忙，TTS、画图、配音各管一摊，但把它们串成一个能跑通的流水线，让旁白、画面、字幕、手绘节奏真正对齐，多数人依然卡在「只会单独玩玩」的阶段。CS Board（白板声画工坊）把这条流水线压缩成一个本地工作台，Star 数 768，主语言 Python，目标是：上传参考音频、粘贴中文文案、点一下，得到 MP4。

## 二、项目定位：它解决的是什么问题

CS Board 把自己定位为「本地 AI 视频制作工作台」。它的核心特性可以压缩成四个关键词：本地音色克隆（接 IndexTTS 2.5 Gradio/FastAPI，参考音频不离开本机）、12 套视觉模板（覆盖极简白板、国风、赛博霓虹、黑金发布会、3D 黏土等）、动态信息图（按真实旁白时间逐项呈现图文，避免画面抢跑）、任务复用与恢复（配音、分镜、图片、分段视频均有检查点）。素材、密钥、任务历史和成片默认保存在本机 `.webapp/` 目录；同局域网团队可共用制作队列，个人制作偏好保留在各自浏览器。这一版本相比上一个版本新增了独立的音色库、画风库、IndexTTS 设置页面、文生图工作台，以及按对象分组的手绘节奏优化。

## 三、核心功能深度解析

### 1. 三种制作模式覆盖大多数中文视频场景

「标准制作」适合先快速验证内容方向：上传音频和文案，选个视觉模板，系统按场景拆解、统一画面风格，合成白板动画。「自定义参考」适合固定 IP 或品牌化内容：再加一张风格参考图，以及最多 5 个角色、每个角色 1–3 张参考图；系统会按文案调度角色，不会直接复制参考图中的人物。「动态信息图」适合需要「边讲边理解」的内容：先依据真实旁白生成短语时间表，再生成章节、核心观点与图文结构；任何图文元素都只在对应语音开始后才出现，避免画面抢跑或拖后。三种模式共用同一个音色和文案输入，切换零成本。

### 2. 本地音色库与 33 个示例音色开箱即用

参考音频管理是从「散落在文件夹」升级到「集中工作台」的关键。CS Board 提供独立的 `/voices` 页面：可按名称、文件名、格式搜索，分页浏览、试听、新增、重命名与删除，音色保存在 `.webapp/voices/`。仓库自带了 33 个真实示例音色，分 5 页展示，包括川普（Qwen3）、孙悟空、猪八戒、唐僧、沙僧、林黛玉、贾宝玉、曹操、佩奇、蜡笔小新、新闻播报、纪录片解说、童声等——这些是音色库展示内容，下载后并不会默认附带。最关键的一点是：任务提交时会将音色复制到任务目录，因此之后删除或重命名音色不会影响已经生成的历史任务。

### 3. 中文读音、术语、连字符的细粒度预处理

TTS 文本预处理只影响发送给 IndexTTS 的文本，原文仍用于分镜、页面内容和字幕。生成语音前会自动保护 `GPT-5`、`Qwen3-TTS` 等技术术语，并把普通连字符按上下文转换：数字范围如 `3-5` 转为「3到5」，负数如 `-2` 转为「负2」，其他连字符转为停顿。多音字短语写在根目录的 `pronunciation.yaml`：

```yaml
phrases:
  - phrase: 银行
    char: 行
    pinyin: HANG2
```

这样「银行」会只在 TTS 文本中转换为「银`<行|HANG2>`」；分镜、页面和字幕仍保留原文。需要新增读音时只需增加一条包含 `phrase`、`char`、`pinyin` 的规则。

### 4. 独立文生图工作台复用同一套 API 配置

新增的 `/image-generator` 让用户在不提交视频任务的情况下单独生成图片：输入提示词，可选共享画风库中的风格，使用已配置的图片模型服务，支持尺寸与质量设置，生成结果可预览、下载 PNG。最近 4 张结果只保留在当前页面会话中，刷新后不会进入视频任务历史。这对「先试几张图看看风格对不对」的工作流非常友好，避免一次失败就要重做整支视频。

## 四、技术亮点与性能数据

CS Board 的技术栈围绕「本地化 + 检查点恢复」展开。前端是 React，后端是 FastAPI，视频渲染部分使用 Remotion（动态信息图模式需要），推理侧依赖外部 IndexTTS 2.5 服务（Gradio 通常 `http://127.0.0.1:7860`，FastAPI 通常端口 `8000`），图像与文本生成走 OpenLux 兼容接口（默认 `gpt-5` 拆文案，默认 `gpt-image-2` 出图）。架构亮点有三：一是任务复用与恢复——配音、分镜、图片、分段视频与成片都有检查点，调整渲染设置不需要重新调模型；二是对象级手绘节奏——相邻笔画按对象连续绘制，结合笔画长度与转折复杂度分配时间，避免跨对象跳笔；三是可配置视频输出目录——最终 MP4 可另存到指定目录，中间图片、音频和检查点仍保留在 `.webapp/jobs/<任务 ID>/`。可控成片节奏覆盖 `16:9` 横屏、`9:16` 竖屏和 `1:1` 方形比例，另有字幕开关、笔身账号名、4 档线条绘制量，以及每张图承载 1–4 个分镜的密度设置。

## 五、适用场景与人群

具体场景一：知识口播类短视频创作者，需要把一篇文章快速转成白板讲解视频，「标准制作」模式配合极简粗线简笔白板风即可。

具体场景二：观点表达与商业分析，需要让数据或论点随旁白逐步展开，「动态信息图」模式的语义时间契约就是为这类内容设计。

具体场景三：固定 IP 或品牌化内容的批量产出，例如系列课程、企业宣传片，「自定义参考」模式支持 1 张风格图 + 最多 5 个角色，使系列感稳定。

适合谁：愿意在本地跑 IndexTTS 与 Python 服务、追求素材可控与隐私安全的独立创作者、中小团队、需要稳定可复用流水线的内容工作室。不适合谁：完全不想本地安装 Python 与 Node.js 环境的纯 SaaS 用户（虽然官方提到可通过秘塔 MiniMax H3 视频生成 API 减少自建）；以及需要 4K 高帧率电影级成片的专业影视团队（输出按 1.6K 内的白板动效为主）。

## 六、竞品对比

| 项目 | CS Board | Pika / Runway 等闭源 SaaS | 通用 TTS + 剪辑工具拼接 |
| --- | --- | --- | --- |
| 音色来源 | 本地 IndexTTS，参考音频不离开本机 | 云端，仅支持平台音色或上传条款受限 | 多样但每段单独跑 |
| 中文读音控制 | pronunciation.yaml + 自动术语/连字符处理 | 一般没有 | 需要手动干预 |
| 视觉与手绘动画 | 12 套模板 + 对象级手绘节奏 | 通用视频生成，无白板笔画动画 | 需要 AE/PR 手工做 |
| 旁白与画面同步 | 语义时间契约驱动，逐项展开 | 靠 prompt 推断 | 靠人工对轨 |
| 检查点与复用 | 配音/分镜/图片/分段/成片都有 | 无 | 无 |
| 部署 | 本地，`.webapp/` 自管 | 云端 | 本地多软件拼装 |

选择 CS Board 的核心理由：当你需要一条「会说话的白板」，并且希望这条生产线完全在本机、可复用、可调音读音、可分批重做单张图时，市面上闭源 SaaS 与手工拼接都做不到。

## 七、如何快速上手

环境要求：Python 3.11+、Node.js 22.13+、FFmpeg 与 FFprobe 已加入 `PATH`、可访问的 IndexTTS 2.5 服务、OpenLux API Key（文本与图片模型权限）。

Windows 一键：
```bash
git clone https://github.com/ChenShuo2004/cs-board.git
cd cs-board
python scripts/prepare_env.py
.\.venv\Scripts\python.exe -m pip install -r webapp\requirements.txt
Push-Location web; npm ci; Pop-Location
.\start-webapp.ps1
```

macOS 一键：
```bash
brew install python@3.13 node ffmpeg
python3.13 scripts/prepare_env.py
.venv/bin/python -m pip install -r webapp/requirements.txt
(cd web && npm ci)
./start-webapp.sh
```

脚本会启动前后端并打开 `http://127.0.0.1:13000/`，同局域网设备可使用脚本输出的地址访问。首次运行打开右上角「API 设置」，填写 OpenLux API Key、文本模型、图片模型（默认 `gpt-5` + `gpt-image-2`）、IndexTTS 地址与接口类型、视频输出目录，然后上传 10–30 秒单人参考音频、粘贴至少 10 字中文文案、选择制作模式与视觉模板即可开始。进阶建议：先用 `/image-generator` 单跑几张图验证风格，再走完整视频任务；遇到多音字直接在 `pronunciation.yaml` 里增加规则；想要复刻历史结果，就在「生成历史」里搜任务名并点击「复用本次设置和素材」。

## 八、总结与行动建议

CS Board 把音色克隆、内容拆解、插画生成、手绘动画、字幕与音画合成压在同一个本地工作台里，对追求素材可控、流程可复用的中文口播创作者非常实用，三种制作模式覆盖了从快速验证到品牌化产出的不同阶段。建议先把 IndexTTS 2.5 服务和 OpenLux API 配好，再用 `/image-generator` 与小段音频试一条 30 秒以内的白板短片，确认模板与节奏符合预期后再进入正式长片。如果对视频生成 API 不想自建 GPU，可参考项目赞助方案接入 MiniMax H3（768P 0.09 元/秒、2K 0.15 元/秒，API 兼容 OpenAI 协议）。仓库地址：[https://github.com/ChenShuo2004/cs-board](https://github.com/ChenShuo2004/cs-board)。一句话推荐：把一段文案做成会说话的白板视频，从现在起，本机一个人就能完成。
