# 一、开篇：如果有个工具能替你做完这一步…

周末晚上，你刚让 Claude Code 改一个棘手的 bug，Cursor 还在跑另一个特性分支，Codex 在生成测试用例。你想看一眼进度，得在三个终端标签页之间来回切；想临时加点需求，得坐到电脑前敲字；想让它跑完自动 commit，得自己写个 cron。一个项目跑三个 agent，已经开始乱成一团。

更头疼的是，你出门买菜时 agent 卡在「需要用户确认」上，等你回来发现任务队列已经积压了 20 分钟。

如果有个工具能把多 agent 编排、跨设备接管、定时任务、git diff 评审全部装进一个面板，你只需要说一句「去做」，它就把流程跑完——这就是 Vicoa 要解决的事。

# 二、项目简介：它到底是什么？

Vicoa 是一个开源、自托管的 AI 编排器（agentic IDE），定位是「从桌面、手机、VPS 调度一支编码 agent 团队」。它不替代 Claude Code、Codex、Cursor 这些 agent，而是把它们当成「员工」统一管理。

核心关键词：
- **多 agent 协同**：内置 40+ 编码 agent，支持 Claude Code、Codex、OpenCode、Cursor、GitHub Copilot、Kimi 等。
- **跨设备控制**：macOS / Windows / Linux 桌面 + iOS / Android 原生 App + Web + CLI。
- **自托管开源**：AGPLv3 协议，Docker 一键起完整栈。
- **BYO-key**：用自己的订阅和 API Key，不锁模型。

项目目前 GitHub 500 Stars，主仓库 Python + Next.js + Flutter + Electron 多端齐全，处于快速成长期。

# 三、核心功能深度解析

### 1. 多 agent 并行与 worktree 隔离

Vicoa 给每个 agent 分配独立的 git worktree 和分支，让 Claude Code、Cursor、Codex 在同一个仓库里并行干活而互不踩踏。原来你需要手动 `git worktree add`、切分支、配置环境，现在点「New Session」就能选机器、选 agent、输 prompt。统一状态面板替代了散落的 tmux 窗口。

### 2. 全设备会话同步

你在 Mac 上开的会话，会自动出现在 iPhone、Android、Web 端。Agent 卡住时手机推送通知；你用语音口述需求（dictation）发出去，agent 接着干。这种「从桌面起跑、用口袋接管」的体验，区别于普通的「远程 SSH 进 shell」。

### 3. 内置差异与终端预览

会话面板里直接看文件级 diff、commit 历史、文件树、嵌入式终端，手机端也能开 live preview 实时查看本地 dev server。代码评审不用切到 GitHub。

### 4. 自动化与任务板

Cron 表达式触发自动任务，任务看板支持 plan → start session → 自动派发 agent 的工作流。CLI 端还能让 agent 自己调 `vicoa` 命令，形成「agent 操作 Vicoa」的元编程闭环。

# 四、技术亮点与性能数据

Vicoa 的架构是经典的多端 + 后端 + 本地守护进程：

- **Web/桌面**：Next.js 15 + React 19 + shadcn/ui，文档站用 Fumadocs。
- **桌面壳**：Electron，内嵌 daemon 进程。
- **移动端**：Flutter 一套代码出 iOS 和 Android。
- **后端**：Python 3.10+ / FastAPI，双层 REST（用户面 + agent 面）+ WebSocket 实时推送，PostgreSQL + SQLAlchemy + Alembic。
- **Agent 运行时**：本地 `vicoa` 守护进程 spawn 出 agent CLI，session 消息走 WebSocket。

亮点在于**协议抽象**：Claude Code、Codex、Pi、Oh My Pi、Antigravity 走原生集成，其余 30+ agent 通过 Agent Client Protocol（ACP）接入，意味着任何遵循 ACP 的 agent 都能即插即用。

性能上，会话消息走 WebSocket 实时同步，状态面板聚合所有 agent 状态刷新无明显延迟（具体数值项目未公开）；自托管用户用 Docker Compose 一条命令起完整栈。

# 五、适用场景与人群

**适合谁**：
- 同时用 Claude Code、Cursor、Codex 多工具的 AI 重度用户；
- 多设备办公、需要随时介入 agent 任务的独立开发者；
- 团队需要统一管理多个 AI 编码任务的 Tech Lead；
- 对数据敏感、希望自托管的企业团队。

**不适合谁**：
- 只用一个 agent、且只在固定一台机器上干活的人——加一层 Vicoa 反而冗余；
- 只想用现成 SaaS、不愿维护 Docker 的纯小白用户。

典型场景：① 让三个 agent 并行写不同模块；② 出差时手机上派需求、回家电脑上审 diff；③ cron 自动让 agent 每晚跑测试 + 提 PR。

# 七、如何快速上手

**桌面端（推荐新手）**：
1. 访问 [vicoa.ai/download](https://vicoa.ai/download) 下载 macOS / Windows / Linux 客户端；
2. 注册并登录；
3. 至少装一个支持的 agent CLI（如 `npm i -g @anthropic-ai/claude-code`）并登录；
4. 点「New Session」→ 选机器、选 agent、输 prompt；
5. 手机装 iOS / Android App，同账号登录，会话自动同步。

**CLI 派**：
```bash
npm i -g @vicoa/cli
vicoa
vicoa daemon    # 仅连接本机做守护进程
```

**自托管派**：
```bash
cp .env.example .env
./backend/scripts/generate-jwt-keys.sh selfhost/keys
docker compose -f docker-compose.selfhost.yml up -d
```

进阶建议：先用官方 Desktop 跑通一个 session，再试 ACP 接入自定义 agent，最后上自托管。

# 八、总结与行动建议

Vicoa 的核心价值一句话总结：**把一群编码 agent 变成一支可调度、可观测、可远程接管的工程团队**。对多 agent 重度用户来说，它省下的不是一行代码，而是「在 6 个终端标签页之间找状态」的精神损耗。

使用建议：从一个熟悉的工作流开始（比如把 Cursor 跑的 agent 接入 Vicoa），体验跨设备同步；再扩展到 cron 自动化；最后评估自托管需求。
