# Recordly：开源录屏神器，零剪辑功底也能产出专业 Demo 视频

## 一、开篇：你还在为录屏这件事头疼吗？

产品经理："帮我录个新功能演示视频，明天客户要看。"
开发者："录是录了，但鼠标飞得飞快，画面糊成一团……找动效设计师加缩放、加光标动效？预算 5000，工期一周。"

录屏工具遍地都是，从 OBS 到 Loom 再到各类国产录屏软件，但真正的痛点藏在录完之后：缩放跟随、鼠标平滑、光标动效、摄像头气泡、背景美化、导出压缩。多数工具只负责前 10%，剩下 90% 的"成片化"工作要么不会做、要么另收费。Recordly 选择把这 90% 也免费塞进一个桌面 App。

## 二、项目简介：用一句话概括

Recordly 是一款面向 Demo / 演示 / 产品介绍场景的**开源桌面录屏与剪辑工具**，主打"录完即成片"。GitHub 已收获 **31602+ Stars**，主要使用 TypeScript 开发，支持 macOS、Windows、Linux 三平台，遵循 AGPL 3.0 开源协议。

核心定位四个关键词：**自动缩放、鼠标美化、摄像头气泡、扩展生态**。

## 三、核心功能深度解析

### 1. 自动缩放 + 鼠标平滑，让画面跟着操作走

传统录屏最尴尬的地方：用户点了某个不起眼的小按钮，观众根本看不清在点哪。Recordly 内置基于光标活动的**智能缩放建议**，会在点击密集区域自动生成放大关键帧；同时提供**光标平滑、运动模糊、点击回弹、悬停摇摆**等效果，把"狂野鼠标"修饰成"专业演示级"动效。导出时还会用 macOS 风格光标资源替换原生指针，跨平台输出一致。

### 2. 动态摄像头气泡，主播级画面

很多人录教程希望出镜，但摄像头画面太大又会喧宾夺主。Recordly 的解决方案是**悬浮气泡式摄像头**：预设九宫格位置或自定义 X/Y 坐标，可镜像、可调圆角与阴影，**还能在画面放大时自动缩小自身比例**，避免遮挡关键操作区。这相当于把 OBS 的画中画配置做成了"点两下"的预设。

### 3. 时间轴编辑，为 Demo 而生

时间轴不是简单的剪辑轨道，而是为录屏场景特化：拖拽式缩放区、变速区、裁剪、文本/图片/形状标注、附加音轨都通过同一根轨道管理。项目保存为 `.recordly` 文件，下次打开自动续上。光标样式、摄像头位置、背景美化参数全部随项目持久化，不必每次重录都重新调一遍。

### 4. 框架美化 + 扩展市场

录完直接套上**壁纸、纯色、模糊背景**，加上圆角、阴影、Padding，一秒从"窗口录像"变成"成片"。官方还开放了**社区扩展市场**：点击色音效、设备边框、浏览器 Mockup、壁纸包、渲染钩子都能由第三方扩展提供，类似 VS Code 的插件生态。

## 四、技术亮点与性能数据

- **原生捕获层**：macOS 调用 ScreenCaptureKit、Windows 调用 Windows Graphics Capture（WGC）+ WASAPI 音频，Linux 走 Electron 捕获；同一抽象层封装，跨平台体验相对一致。
- **PixiJS 渲染**：预览和导出共用同一套场景合成逻辑，所见即所导出。
- **项目文件格式**：`.recordly` 记录源媒体路径 + 编辑器状态，可重入、可版本管理（适合团队协作）。
- **导出格式**：MP4、GIF 双格式可选，GIF 支持帧率、循环、尺寸预设。
- **系统要求**：macOS 14.0+ / Windows 10 Build 19041+ / 现代 Linux 发行版。

## 七、如何快速上手

**1. 下载安装**
前往 GitHub Releases（https://github.com/webadderallorg/Recordly/releases ）下载对应平台安装包；Arch 用户可直接 `yay -S recordly-bin`。

**2. 首次录制**
打开 Recordly → 选择屏幕或窗口 → 勾选麦克风与系统音频 → 点击录制 → 结束自动跳入编辑器。

**3. 最小成片流程**
录制完成后：点"自动缩放建议"接受推荐 → 调整光标样式为 macOS 风 → 添加摄像头气泡到右下角 → 套用深色渐变壁纸背景 → 导出 MP4。

**4. 进阶**
- 在时间轴添加变速区，让等待过程 2x 播放。
- 访问 Marketplace 安装点击音效、设备边框等扩展。
- 项目保存为 `.recordly`，便于后续增量修改。

**5. 源码构建**
```bash
git clone https://github.com/webadderallorg/Recordly.git recordly
cd recordly
npm install
npm run dev
```
按平台打包可使用 `npm run build:mac` / `build:win` / `build:linux`。
