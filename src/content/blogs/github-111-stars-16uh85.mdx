# 一万字没一句抒情，却把读者看哭：GitHub 这个 111 Stars 的写作心法，把"不煽情"做到了极致

## 一、开篇：别再手动折腾它了

写了五年公众号，你有没有这种感觉：素材明明很扎实，经历也确实动人，但写出来就是寡淡得像白开水。

打开稿子一看，问题一目了然——通篇都是「我感到心酸」「我们终究还是走散了」「也许人生就是这样」。每一个形容词都在用力喊，但读者翻了两屏就划走了。

更扎心的是，你看完一篇一等奖作品复盘贴，发现人家一万字没一句抒情，没一处评论，反而把你看哭了。差距到底在哪？

一个叫 `new-concept-writing` 的 GitHub 项目把这件事拆开了。它 111 Stars，不教你华丽辞藻，不教你结构模板，它只做一件事：把情感从形容词里抠出来，全部塞进数字、物件、重复和留白里。

![](/assets/blog-images/github-111-stars-16uh85/img02.webp)

## 二、项目定位：它解决的是什么问题

`new-concept-writing` 不是一个普通写作工具，它是一份「新概念一等奖写作 Skill」。所谓 Skill，就是一份喂给 AI 的写作指令集，让 AI 学会这套「用最少的话承载最多的情感」的心法。

它的核心特性可以概括为四个关键词：**数字承重、物件代替心理、重复与打破、零解释**。它解决的痛点极其明确：写作者（尤其是用 AI 辅助写作的人）总忍不住用情绪词煽情，结果越用力越廉价。

项目的形态很轻：一个 GitHub 仓库，一份 SKILL.md，外加一个推荐使用模型 Opus 4.6。它的存在方式不是工具，是「写作纪律」。

## 三、核心功能深度解析

### 1. 数字做情感的工作

项目反复强调一个原则：情感不要用形容词写，要用数字写。

比如不要说「我很犹豫」，写「我犹豫了三天」。不要说「我们差距很大」，写「一百五十块的羽绒服，一亿五千万的电影」。一颗卵子三点五微克，五千万美元两点五吨。重量、金额、时间，这些物理单位进入文本的瞬间，读者会自动在脑子里换算——换算的过程，就是代入的过程。

这就是数字承重的秘密：它绕过了读者的防御机制。

### 2. 物件代替心理描写

传统写法里，写思念就要写「我无时无刻不在想她」。这套 Skill 的做法是：拿出一个具体物件。

一张 2007 年存的 QQ 图片，分辨率糊得很，十九年每换一台设备都导过去。一支没拆的促排针，冷藏八天，从洛杉矶寄回来的箱子。一把指甲锉，磨了两下，忘了方向，放回去了——结尾是「我的指甲现在还是磨人的」。

物件不替作者说话，它把判断权完全交给读者。读者看到一个被反复迁移的 QQ 图片，自己会读出十九年的分量。

### 3. 重复结构与打破

项目里有一个经典案例。「她说去看电影吧，我说好。她说给彩礼，我说好。她说特纳里费，我说好……」这种「她说……我说好」的结构连续出现十几次，节奏已经把读者裹挟进去，建立了一种「这个男人什么都顺从」的预期。

然后——「她说，五千万，美元。我说，让我想想。」

一句打破，前面所有的「好」全部翻面。这就是结构的力量：先建立惯性，再打断惯性。读者被打断的那一瞬间，情感就来了。

### 4. 零解释，信任读者

这是这个 Skill 最反常识的一条。通篇都在说「不要告诉读者为什么」「不要解释人物动机」。

「我全部相信她说的。但是我一个字也不信。」这两句话放在一起，作者没说为什么，留白让读者自己去体会。一个人怎么可以同时全信和全不信？情感张力就在这个矛盾里炸开。

项目还附带了一张「禁用清单」，比如把「我感到悲伤」换成「我把手机放在床头柜上，屏幕朝下」；把「我们之间的差距太大了」换成「一百五十块。一亿五千万。」；把「也许人生就是这样」直接删掉，不写。

## 四、技术亮点与性能数据

这套 Skill 本身不是软件，但它有几个非常值得说道的设计亮点：

**心法统领技巧**：项目开篇先定调——「写的时候，脑子里应该有读者此刻的状态」。所有技巧都服务于四个问题：读者现在判断什么？期待什么？缺什么信息？张力有多高？这种「以读者状态为锚」的写法，比任何模板都通用。

**真实语料驱动**：项目里的所有例子都不是编的，来自一篇真实的一等奖文章复盘。这让 Skill 不是抽象理论，而是可对照的范式。

**模型匹配严格**：项目作者明确写「唯一推荐 Opus 4.6」。理由是「克制需要判断力，小模型做不到」。这种坦诚比任何技术指标都重要——它告诉你什么时候该用什么工具。

## 五、适用场景与人群

**真实情感故事**：项目原话是「真实情感故事，配合语音输入最佳」。它不适合虚构创作、营销文案、技术博客。

**具体三类用户最合适**：第一，公众号写作者，尤其是情感号、人物特写号；第二，非虚构写作者，需要处理采访素材的人；第三，用 AI 辅助写作但总被 AI 写出「AI 味」困扰的人。

**不太适合**：需要快速产出 SEO 文章的运营、需要数据论证的深度报道、需要逻辑推演的评论文章。

## 六、竞品对比

| 维度 | 传统写作教程 | 通用 AI Prompt | new-concept-writing |
|------|------------|---------------|---------------------|
| 教学方式 | 抽象理论 | 模板填空 | 心法+范式+禁用清单 |
| 核心目标 | 文采华丽 | 产出效率 | 情感克制 |
| 模型要求 | 无 | 兼容所有 | 明确指定 Opus 4.6 |
| 适用文体 | 通用 | 通用 | 真实情感故事 |
| 反 AI 味 | 无 | 反而加重 | 专门对抗 |

市面上的写作 Skill 大多教你「怎么写得更好」，这个项目教你「怎么忍住不写」。这种反向教学在内容创作领域相当稀缺。

## 七、如何快速上手

**第一步：阅读 SKILL.md**。直接访问 `https://github.com/orange2ai/new-concept-writing`，通读心法和技巧两个部分。

**第二步：喂给 AI**。复制这段指令发给 AI：

> 请读取 https://github.com/orange2ai/new-concept-writing 中的 SKILL.md，学会这套写法，然后用它帮我写一篇关于 [xxx] 的故事。

**第三步：配合 Opus 4.6**。作者推荐在 [Cola](https://colaos.ai) 直接使用 Opus 4.6，因为小模型压不住克制的判断力。

**进阶建议**：先用这个 Skill 改写自己过去的一篇旧作，亲眼看看「形容词被替成物件」之后文字密度的变化。

## 八、总结与行动建议

`new-concept-writing` 不是一个工具，它是一份写作纪律。它告诉所有写作者：情感不是喊出来的，是藏起来的。藏在三点五微克里，藏在磨错方向的指甲锉里，藏在十九年都舍不得删的糊图里。

如果你正在写一个真实故事，却被「怎么写得更动人」卡住，去读一遍这个项目的 SKILL.md，然后忍住，删掉所有「我感到」，让数字、物件和留白替你说话。

**项目地址**：https://github.com/orange2ai/new-concept-writing

**推荐模型**：Opus 4.6（[Cola](https://colaos.ai) 可直接使用）

克制，是最难学的技巧，也是最值钱的技巧。
