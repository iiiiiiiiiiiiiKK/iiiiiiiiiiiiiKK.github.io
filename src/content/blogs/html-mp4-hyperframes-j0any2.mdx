# HyperFrames：用 HTML 直接渲染 MP4，AI Agent 也能拍视频

## 一、你还在为这件事头疼吗？

做一条产品发布视频，团队成员需要分别对着 PR、脚本、配乐、动效、色卡折腾好几天；想让 AI 帮忙，它却卡在「不会用 Remotion」「不熟悉时间轴」「不会写 React 组件」上；好不容易导出一版，下一次 CI 重跑又变了样，难以回归。

更麻烦的是，网页里那些漂亮的 CSS 动效、GSAP 时间线、Lottie 动画，到了视频渲染管线里要么丢失、要么时刻对不上。开发者写一遍前端，设计师再翻译一遍 After Effects，工程团队再写一遍 React 组件——三套表达，三个真相。

66.4k Stars 的开源项目 HyperFrames 给出了一种反直觉的答案：**视频就是 HTML**。

![](/assets/blog-images/html-mp4-hyperframes-j0any2/img02.webp)

## 二、项目定位：它解决的是什么问题

HyperFrames（heygen-com/hyperframes）是 HeyGen 开源的「HTML 原生视频」框架。它把 HTML、CSS、媒体和可寻址动画（seekable animation）转换成确定性的 MP4 视频，可本地 CLI 使用，也可由 AI 编程 Agent 通过 skills 调度，还支撑 HeyGen 托管的创作工作流。

四个关键词：HTML 原生、面向 Agent、确定性输出、零构建步骤。已在 HeyGen 生产环境使用，生态引入方包括 tldraw、TanStack 等团队，License 是 Apache 2.0，无每帧计费、无商业门槛。

![](/assets/blog-images/html-mp4-hyperframes-j0any2/img03.webp)

## 三、核心功能深度解析

### 1. HTML 即视频：组合即代码

HyperFrames 的核心契约是一段带 data 属性的 HTML。用 `data-composition-id`、`data-start`、`data-duration`、`data-track-index` 把每个元素声明成时间轴上的一个 clip：视频、文本、音频、原生 div 都可以。下例展示一个 6 秒片头：前 1 秒后标题淡入，背景视频与音乐同步播放。

```html
<div id="stage" data-composition-id="launch" data-start="0" data-width="1920" data-height="1080">
  <video class="clip" data-start="0" data-duration="6" data-track-index="0" src="intro.mp4" muted playsinline></video>
  <h1 id="title" class="clip" data-start="1" data-duration="4" data-track-index="1">Launch day</h1>
  <audio data-start="0" data-duration="6" data-track-index="2" data-volume="0.5" src="music.wav"></audio>
  <script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
  <script>
    const tl = gsap.timeline({ paused: true });
    tl.from("#title", { opacity: 0, y: 40, duration: 0.8 }, 1);
    window.__timelines = window.__timelines || {};
    window.__timelines.launch = tl;
  </script>
</div>
```

它和 React 时间线工具最大的差别是：**没有构建步骤**，index.html 直接可预览、可渲染；Agent 拿到的也是纯 HTML，不用懂 JSX、bundler、组件生命周期。

### 2. 可寻址动画：6 套运行时自适应

视频渲染最大的坑是「动画对不准帧」。HyperFrames 提供 frame adapters，把 GSAP、CSS、Lottie、Three.js、Anime.js、WAAPI（甚至 TypeGPU）都改造成**可寻址**形式——渲染器 seek 到任意秒，动画就停在该刻的状态，导出的 MP4 帧帧匹配，CI 可回归。

### 3. CLI + 云端渲染两条路

本地三步走：`npx hyperframes init my-video` 起项目，`npx hyperframes preview` 在浏览器里实时预览，`npx hyperframes render` 出 MP4。需要大规模分发时，`hyperframes lambda deploy / render` 部署到 AWS Lambda 分布式集群。引擎是 Puppeteer 驱动 headless Chrome 抓帧 + FFmpeg 编码，依赖只有 Node.js 22+ 与 FFmpeg。

### 4. 21 个 Agent Skills + frame.md 设计层

HyperFrames 团队给 Claude Code、Codex、Cursor、Gemini CLI、IBM Bob 等都做了 skills。`/hyperframes` 是总路由，根据「给我做个产品介绍」「把这个 PR 做成视频」「给这段口播加字幕」等意图分发到 `/product-launch-video`、`/pr-to-video`、`/embedded-captions` 等 10 个创作工作流；它们再按需加载 8 个领域技能（核心契约、动画、关键帧、音频、媒体资源、CLI、注册表、Figma 导入）。

配套的 `frame.md` 把网页端的 `design.md`「反转」给摄像机用：同一个 token 系统，重写一份让 Agent 能直接生成宣传视频的 `DESIGN.md` 超集。官方提供 Biennale Yellow、BlockFrame、Blue Professional 等数十套模板可直接 remix。

## 四、技术亮点与性能数据

- **确定性输出**：同一份 HTML 输入、同一份媒体素材，任意机器、任意时间渲染出的 MP4 字节级一致，专门为 CI 回归、自动化内容生产线设计。
- **零构建链**：`index.html` 直接预览和渲染，省去 webpack/vite/bundler 整条链路，冷启动开销几乎为零。
- **Adapter 抽象**：6 套主流动画运行时通过统一接口暴露「seek 到 t 秒」能力，不绑定某一动画库。
- **分布式渲染**：AWS Lambda 渲染路径覆盖从笔记本到 CI 的全场景，单仓库即可承载大规模并发。
- **生态兼容**：Apache 2.0 协议、无每帧费用、无商业上限；与 tldraw、TanStack 等团队的集成案例已被官方收录在 ADOPTERS.md。

## 五、适用场景与人群

**适合谁**：SaaS 团队的 PR 自动化视频生成；增长团队的产品发布片、社交媒体短片；教育/培训团队把文档或 PDF 转成讲解视频；设计系统团队基于 frame.md 输出品牌一致的动效素材；以及任何已经在写 HTML 的前端/全栈工程师。

**典型场景**：① 给一篇 changelog 自动产出 60 秒解说视频；② 把每周的 GitHub PR 汇总成可视化的代码 diff 走查；③ 把销售数据可视化、做成可分享的图表动画；④ 为现有口播视频批量加嵌入式字幕、lower-third、引用条；⑤ 把音乐节拍同步到 kinetic typography 短片。

**不适合谁**：纯艺术向、追求粒子/水墨/手绘等非规则视觉的电影级项目（这类仍需 After Effects、TouchDesigner 等专业工具）。

## 六、竞品对比

| 维度 | HyperFrames | Remotion |
|---|---|---|
| 创作模型 | 纯 HTML + CSS + 可寻址动画 | React 组件 + 时间轴 |
| 构建步骤 | 无，index.html 直接渲染 | 需要 bundler |
| Agent 协作 | HTML 文件即可交接 | 需要 JSX + React 工程 |
| 关键帧动画 | 6 套 adapter 全部 seek-safe | 需小心处理 wall-clock |
| 分布式渲染 | 本地 + AWS Lambda | 成熟的 Remotion Lambda |
| License | Apache 2.0 | Source-available，商用受限 |

简单说，Remotion 的赌注是「用 React 写视频」；HyperFrames 的赌注是「用 HTML 写视频，而 HTML 恰好是 Agent 最擅长写的语言」。

## 七、如何快速上手

**前置依赖**：Node.js 22+、FFmpeg。

**路径 A：AI Agent 路线（推荐）**
```bash
claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes
```
启用后对 Agent 说一句：「用 `/hyperframes` 做一个 10 秒的产品介绍，要有淡入标题、背景视频和轻音乐。」Agent 会自动走 plan → HTML → 动画 → 媒体 → lint → preview → render 的完整生产链。

**路径 B：CLI 路线**
```bash
npx hyperframes init my-video
cd my-video
npx hyperframes preview
npx hyperframes render
```
**路径 C：复用已有组件**
```bash
npx hyperframes add flash-through-white
npx hyperframes add instagram-follow
npx hyperframes add data-chart
```
上手后记得跑 `npx hyperframes init` 保持 core skills 最新；CI 中用 `npx hyperframes skills update` 精确拉取核心集合。

## 八、总结与行动建议

HyperFrames 把视频创作从「时间轴 + React」拉回到「HTML + CSS」，并顺势解决了 AI Agent 最痛的「不会写视频工程」问题：同一份 `index.html`，人可以直接预览、Agent 可以自动渲染、CI 可以回归比对。

如果你是前端工程师，从 `npx hyperframes init` 起一个 30 秒的片头试试；如果你是 Agent 重度用户，给 Claude Code / Cursor 装上 `claude plugin install hyperframes@hyperframes` 然后让它替你产出内容素材；如果你已经在用 Remotion，仓库还提供了 `/remotion-to-hyperframes` 单向迁移 skill。
