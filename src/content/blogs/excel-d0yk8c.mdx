# 独立插画师还在用 Excel 排单？这个本地工具帮你把接单到收款全打通

## 一、开篇：你还在为这件事头疼吗？

插画师接单，最怕的不是没活，而是活多到乱成一锅粥。

甲方 A 的截稿日是下周二，B 客户刚付了定金要追加细节，C 平台抽成 20% 你算完才发现到手没几个钱，D 稿子画完三个月还没收到尾款——这些场景，独立插画师几乎人手经历过。

更让人头疼的是工具选择：商业项目管理软件动辄几百块一年、强制云端同步、客户信息上传第三方；Excel 表能记账却画不出甘特图，手机日历能排期却记不清分期到账日。

一款专为独立插画师设计的本地排单工具 **oimimo 画师排单助手** 在 GitHub 上线，覆盖「接单 → 排期 → 跟进 → 收款 → 统计 → 归档」全流程，数据全部存在本地 SQLite 文件里，无需联网、无需账号。

## 二、项目简介：它到底是什么？

**oimimo 画师排单助手** 是一个面向独立插画师的本地化订单与排期管理工具，主语言 Python，基于 Flask 3 + HTMX 2 构建单文件离线应用。

- **定位关键词**：本地存储 / 全流程闭环 / 插画师专属
- **当前状态**：GitHub 47 Stars，处于早期但功能已经相当完整
- **核心特色**：零云依赖、零账号、零月费，单文件 SQLite 即装即用

## 三、核心功能深度解析

### 1. 甘特图 + 日历双视图排期

主页仪表盘内置自研 SVG 甘特图，支持日/周/月/年四档视图，订单块可拖拽改期并自动保存。日历视图（基于 FullCalendar 6）支持月/周切换，未排期订单池可拖入历，事件可拖拽调时长。

最实用的一点：5 种着色模式——按来源（米画师/小红书/朋友介绍）、按阶段（草稿/精修/完稿）、按截稿日、按收款、按稿件类别切换着色，一眼看清本周该优先推哪单。

### 2. 分期收款 + 先折后费计算链

订单支持整单收款与分期收款两种模式，每笔分期到账日归属对应月份，收款时间线逐笔记账，最后一期收齐自动结算归档。

计费链严格按行业惯例：报价金额 → 应用折扣（VIP 客户自动带出折扣）→ 扣除平台手续费 → 得到实际到账。系统会自动算出"你报价 1000 元、平台抽 20%、客户是 VIP 9 折"之后真正到手多少钱，避免月底对账时才发现利润被吃掉一大块。

### 3. 收入看板与时薪统计

收入看板用 gridstack 支持自定义布局，呈现月度收入、年累进曲线、品类分布饼图。内置时薪统计：把你当月总到账除以实际画稿小时数，告诉你这个月时薪到底是 80 元还是 300 元——这往往是独立插画师最需要却最不愿意面对的数字。

### 4. 价目表与小票打印机

价目表提供长条视图 + 卡片视图双模式，支持多例图展示、分类导出 PNG、价格区间填写、拖拽排序。

小票打印机是隐藏亮点：复古小票样式渲染订单明细（含赠品 / 附加服务 / 倍率折扣 / 条码 / 锯齿边），四套预设样式可保存为模板——给客户交付时打印一张，比单纯发个 PDF 有仪式感得多。

## 四、技术亮点与性能数据

| 维度 | 选型与表现 |
|------|-----------|
| 后端 | Python Flask 3 + Pydantic v2，启动即用，零配置 |
| 数据库 | SQLite WAL 模式单文件，备份只需复制 `orders.db` |
| 前端 | Jinja2 + HTMX 2，无 npm、无构建步骤、无 Node 依赖 |
| 可视化 | 自研 SVG 甘特图 + FullCalendar 6 + Chart.js 4，全部本地 vendor，离线可用 |
| 交互 | SortableJS 看板拖拽、gridstack 自由布局 |
| 打包 | PyInstaller onedir + Inno Setup 6，输出 Windows 安装包与便携版 |

整套技术栈刻意避开任何需要在线编译或云服务的环节，保证插画师在工作室断网环境下也能正常运转。

## 五、适用场景与人群

**适合**：
- 月接单量 5–50 单的独立插画师 / 自由画手
- 同时在 2 个以上平台（米画师、小红书、B站、淘宝等）接单的多渠道创作者
- 对客户隐私敏感、不愿把报价与稿件信息上云的创作者
- 想算清"这个月到底时薪多少"的理性派画手

**不太适合**：
- 团队协作型工作室（这是单机工具，没有多用户权限）
- 需要移动端原生 App 的用户（目前是 Web 应用，需通过 ICS 订阅间接同步手机日历）
- 订单量过百的成熟工作室（建议上专业 ERP）

## 七、如何快速上手

前往 GitHub Releases 下载对应版本：
- `oimimo-setup.exe`：Windows 安装版，双击安装、自选路径、自动建桌面快捷方式
- `oimimo-portable-win64.zip`：便携版，解压即用，U 盘随身带

启动后浏览器自动打开 `http://127.0.0.1:1096`。首次运行若 Windows SmartScreen 提示"已保护你的电脑"，这是未购买代码签名证书的正常现象，点「更多信息」→「仍要运行」即可，源码公开可自行审阅。

**最小可用步骤**：
1. 安装并启动 → 自动打开主页
2. 点击「新建订单」选择模态或抽屉模式填入第一单
3. 拖入日历定排期 → 收到首笔款项时在收款时间线记账

**进阶建议**：
- 在设置里启用「日历订阅」，把生成的 ICS 链接加到手机日历，截稿日会自动同步到 iOS/Android
- 进入「价目表」用预设样式做一份 PNG 发小红书用
- 月底去「收入看板」看一眼时薪数字
