## 一、开篇：为什么你需要这个工具？

短剧团队最近都在抢 AI 工作流，但卡点越来越具体：小说丢给模型，要么角色串戏、要么美术风格飘忽、要么大纲写到一半跑偏。等手工核对完一版，时间已经过去大半天。你想做的不是「让 AI 写小说」，而是「让 AI 直接交出能开拍的物料」——角色设定、集纲、美术资产，一次性齐活。

这件事的难点在于「确定性」：AI 出文字容易，出「能拍」的结构化产物难。每一步都要质量门把关，每次返工都在烧模型额度与制作档期。

## 二、项目简介：一句话说明它是什么

shuohao-skills 是一套给 Claude Code 与 codex 用的 AI 短剧制作 skill 集合，把一本小说拆解成三套可直接进入拍摄流程的产物：角色设定集、短剧改编大纲、美术设定集。

核心关键词：**结构化**、**脚本化质量门**、**软链安装**、**零 npm 依赖**。当前 GitHub Stars 1252，三个 skill 全部自带 selftest，覆盖全量确定性逻辑。

## 三、核心功能深度解析

### 1. novel-characters：把小说拆成角色设定集

输入一篇小说，输出人物画像、形象提示词、音色提示词、角色设定图。报告语言与出图风格都可选，让同一份 skill 适配中文短剧、英文动画、海外市场。它把「角色一致性」这件事前置到拆解阶段，避免后期配音与画风走样。

### 2. novel-outline：短剧改编大纲五件套

输出改编说明、人物表、爽点表、分集梗概、资产清单五份文档，并通过 13 道脚本化质量门检查。它还支持「已有大纲的体检模式」，意味着团队过往的人工大纲可以直接丢进来做合规校验——而不是推翻重来。

### 3. novel-art：场景与叙事道具美术设定集

吃 outline.json 的预填清单，输出含一致性锚点、光照与状态变体、尺度参照、无人无手白底提示词的美术文档，11 道脚本化质量门兜底。它专门为出图模型设计了「无人无手白底」这套提示词约定，避免人物污染纯场景资产。

### 4. 配套工具：install.sh 与 selftest

`./scripts/install.sh` 会自动检测本机是 Claude Code 还是 codex，把 skill 软链到对应目录，`git pull` 后立刻生效。`scripts/selftest.mjs` 不调模型、不花额度、1 秒跑完，适合每次提交前自检。

## 四、技术亮点与性能数据

- **零 npm 依赖**：所有脚本只用 Node 标准库，免去 `npm install`、lockfile 冲突与供应链风险。
- **软链安装**：更新靠 `git pull`，无须重装，CI/容器里也能复用。
- **脚本化质量门**：13 + 11 道门覆盖大纲与美术两套产出，规则可读、可改、可回放。
- **自包含目录结构**：每个 skill 单目录，含 SKILL.md、scripts、references、examples、assets，可独立拷贝到其他工程。
- **平台兼容**：仅在 macOS + Node 24 上验过；无平台相关调用，理论上 Linux 与更低版本 Node 同样适用。

## 五、适用场景与人群

- **AI 短剧工作室**：从小说到分镜脚本的标准化产线，减少「文 → 拍」之间的人工对齐环节。
- **动画与漫剧团队**：需要稳定角色形象与场景资产，art skill 的一致性锚点正好对应管线需求。
- **小说 IP 改编方**：手里有成稿小说，想快速跑出多版本改编方案与美术方向 A/B 测试。
- 不适合：纯文本写作、没有结构化产物需求的轻量场景；需要图形化 GUI 的非技术团队。

## 六、竞品对比

| 维度 | shuohao-skills | 通用 ChatGPT Prompt 模板 | 商业 AI 短剧 SaaS |
| --- | --- | --- | --- |
| 产出结构化 | 三套文档 + 13/11 道质量门 | 自由文本，无门禁 | 黑盒产出，难以二次编辑 |
| 安装成本 | 软链脚本，零依赖 | 无 | 注册付费 |
| 可定制 | skill 源码开放、规则可改 | 模板手抄 | 不开放 |
| 模型选择 | 走当前会话额度，无 API key | 自配 | 通常绑定单一模型 |
| 出图能力 | 走 codex CLI 内置 `$imagegen` | 需外接 | 内置 |

选择它的核心理由：**源码开放 + 结构化产物 + 脚本质量门**，正好补在「Prompt 模板太散、SaaS 太封闭」之间。

## 七、如何快速上手

```bash
git clone https://github.com/eternityspring/shuohao-skills.git
cd shuohao-skills
./scripts/install.sh
```

最小可用流程：在 Claude Code 或 codex 里加载 `novel-outline`，丢入小说文本，让 agent 跑通 13 道质量门；接着加载 `novel-characters` 出角色设定；最后用 `novel-art` 吃 outline.json 出美术设定集。

进阶建议：每次加新 skill 前，先跑一遍 `for f in skills/*/scripts/selftest.mjs; do node "$f"; done`；按需传 `--codex` 或 `--uninstall` 控制安装范围。

## 八、总结与行动建议

shuohao-skills 的核心价值，是把 AI 短剧从「能写的工具」升级成「能拍的产线」：三套结构化产物 + 脚本质量门 + 软链安装，让小团队也能跑出工业级工作流。

使用建议：从 `novel-outline` 入手，先跑一版 13 道门的体检模式，看看现有大纲差在哪；再串 `novel-characters` 与 `novel-art` 做完整闭环。
