## 一、开篇：为什么你需要这个工具？

学中医的人都知道倪海厦。这位被无数经方爱好者奉为「入门必看」的传奇中医，生前留下的人纪系列讲义在民间广泛流传，但真正啃下来的人寥寥无几——伤寒论讲义209页、金匮要略419页、黄帝内经461页，加上神农本草经、针灸、医案，总计2,452页、350万字。

更关键的问题在于：这些讲义之间存在大量交叉引用和辨证逻辑。一个太阳伤寒患者，可能牵连到金匮要略的杂病条文、本草经的药性选择、以及849例医案中的类似案例。普通学习者很难把这些知识串联起来，更别说让AI来模仿倪师的思维模式。

如果有一款工具，能把这350万字蒸馏成AI可调用的诊断思维，让你在问诊时获得「倪海厦视角」的即时反馈——这正是 `nihaixia` Skill 要解决的问题。

![](/assets/blog-images/ai-skill-8-13g3mc/img02.webp)

## 二、项目简介：一句话说明它是什么

`nihaixia` 是 GitHub 上首个将倪海厦（1954-2012）完整中医思维体系蒸馏为可激活 Agent Skill 的开源项目，当前 Star 数 1854，最新版本 v2.1.0。它支持 Claude Code、腾讯 IMA、SkillHub 等5个平台，核心数据覆盖129条伤寒论、23篇金匮、71篇黄帝内经、345种本草、849个医案，以及3.5M字精萃。

项目采用 MulanPSL-2.0 开源协议，激活词为「倪海厦」「海厦视角」「倪师」「经方思维」，让任何 AI Agent 都能瞬间切换到倪海厦的辨证视角。

## 三、核心功能深度解析

### 1. 六经辨证诊断公式（v2.1.0 新增）

这是本次升级的核心，从知识库查询工具进化为具备六经辨证思维模式的临床诊断助手。新增8个诊断公式，每个公式包含 IF-THEN 辨证规则、分型鉴别表、代表方剂，覆盖太阳、阳明、少阳、太阴、少阴、厥阴、少阴热化、合病并病八大场景。

配合「快速诊断流程图」形成从患者症状到六经定位的完整决策树，再配合脉诊速查（8种单脉+8种复合脉）、舌诊速查（5种舌象+6种复合舌象），构建出可执行的诊断路径。

### 2. 七步走辨证思维模式

倪海厦的临床心法被蒸馏为七步标准流程：定表里→分阴阳→辨寒热→判传变→审体质→选方剂→精细加减。这套思维模式打破了AI常见的「头痛医头」式回复，让辨证过程有章可循。

### 3. 经典方剂与药物体系

项目蒸馏了伤寒论129条方剂、金匮23篇，包含完整的组成、剂量、煎服法、禁忌。神农本草经345种药物按三品分类，标注五味归经与炮制要点。例如下辖名方小柴胡汤的口诀——口苦、咽干、目眩、往来寒热，但见一证便是。

### 4. 临床医案库

849例倪师真实医案按癌症、心血管、代谢病、自身免疫、神经精神、其他六大类分类存储，其中癌症医案147例、心血管22例、代谢病12例。每个医案附带倪师的辨证思路与处方选择，为AI回复提供真实的临床参考。

## 四、技术亮点与性能数据

项目数据来源覆盖10份讲义，总计2,452页：伤寒论讲义209页（277K字符）、金匮要略讲义419页（626K）、黄帝内经讲义461页（227K）、针灸教程216页（347K）、神农本草经文稿339页（843K）。

SKILL.md 主技能文件体积仅 4MB，但信息密度达到 11,169 行。v2.1.0 版本新增 476 行内容，其中诊断公式与思维模式集中在第 6097-6545 行。

质量验证方面：达尔文skill评分 9.4/10，10个临床场景测试实现 10/10 覆盖，11个方剂剂量逐方核对 100% 与源文件一致，六经提纲条文核对6条中5条完全一致。

架构上采用模块化设计，9 个知识模块分别对应伤寒论太阳篇/其他五经、医案集、金匮、黄帝内经、梁冬对话、闭门课、汉唐、黄帝内经详注、针灸本草。模块之间通过11处交叉引用实现双向链接，确保诊断公式能精准定位到详细条文。

## 五、适用场景与人群

**适合谁**：经方学习者希望快速检索倪海厦的辨证思路与处方选择；AI Agent 开发者需要为产品注入中医领域专家级知识；中医爱好者希望随时获得「倪师视角」的养生与诊疗建议。

**三个典型场景**：
- 日常感冒辨证：根据症状快速定位六经，给出经方建议
- 方剂查询与对比：查询小柴胡汤、生附子与炮附子区别等具体问题
- 重大疾病参考：查询肝癌、乳癌等147个癌症医案的诊治思路

**不适合谁**：需要专业医疗诊断的急重症患者（项目明确声明仅供学习研究）；追求西药治疗方案的用户；以及不接受中医辨证思维体系的读者。
