做摄影编辑版面还在手动取色？试试 4K Star 的 Photo Abstract Editorial

一晚上只能出 3 张的摄影配图，用这个 Skill 一杯咖啡出十几张

不是滤镜也不是风格迁移：Photo Abstract Editorial 如何把一张照片拆成两层语义

## 一、开篇：别再手动折腾它了

做小红书、Instagram、Verse 专栏编辑的同行大概都经历过这种时刻：手里攒了一组精心拍的照片，想做成「上有原图、下有抽象色块、配一句诗意英文」的竖向编辑版面发出去，于是打开 PS 或 Figma，手动取色、画色块、找字体、调排版、调层叠关系——一张图少说折腾 40 分钟，六张图一晚上就这么过去了。

更尴尬的是成品效果：抽象面板往往和原图「气质对不上」——颜色像随机抽的，构图像另起炉灶，最后只能自我安慰「这是另一种解读」。这种「抽离式再创作」一旦流程不标准化，作品就很容易变得廉价。Photo Abstract Editorial 这个 4K+ Star 的项目，专门解决的就是这个问题：把那张抽象面板的生成过程沉淀成一条可复用的 Prompt 流水线。

## 二、项目简介：用一句话概括

**Photo Abstract Editorial** 是一个面向 Codex 的 Skill，它能把一张照片一键转化为「原始摄影区域 + 抽象记忆面板 + 诗意英文标题」的竖向编辑作品。它定位精准、聚焦三件事：① 保留照片的真实内容；② 仅从照片本身提炼空间关系、构图节奏与色彩关系；③ 内置中英双语完整 Prompt，开箱即用。

它在 GitHub 上已收获 4035+ Star，属于「提示词即产品」类项目中较有代表性的一类。

## 三、核心功能深度解析

### 1. 照片区与抽象面板的版面约束

Skill 在 Prompt 中明确约束成品的物理结构：原图保留在成品的「上方或主要区域」，下方生成由原图关系推导出的极简抽象面板，整张作品只能保留一个原创英文标题（可选副标题）。这种「上图下面板」的版式规定，本质上是为了让作品呈现可预期的编辑感，避免 AI 自由发挥导致版式失控。

### 2. 「可追溯」的抽象化原则

这是这个 Skill 最值得称道的部分。提示词严格规定：抽象面板中的每个重要元素，都必须能追溯到原照片中真实存在的空间、色彩或结构事实。换句话说，你不能凭空捏造一个红色色块贴在原图下面——红色必须来自原图。

这与常见的「滤镜」和「风格迁移」有本质区别：滤镜是统一套用效果，风格迁移会把原图重画，而 Photo Abstract Editorial 坚持「只复刻关系、不复刻细节」。这种「关系优先」的抽象策略，让作品同时具备辨识度与编辑感。

### 3. 高度可调的抽象参数

Prompt 不是死规定，而是「高质量起点」。用户可自由调整五个维度：① 照片与面板的高度比例与画布比例；② 象牙色面板背景、提取色饱和度与主色数量；③ 抽象形式（色块、有机质感、弧形笔触、短条、层叠色带、简化建筑质感、细线、点状标记）的混合比例；④ 母题位置、标题位置、字体气质、是否使用副标题；⑤ 抽象程度（在「关系优先」和「保留少量身份特征」之间滑动，例如地标建筑可保留更多辨识线索）。

![](/assets/blog-images/4-k-star-photo-abstract-editorial-r2yfz5/img03.webp)

### 4. 双语完整 Prompt 资产

仓库自带中英两个版本的完整 Prompt：`photo-abstract-editorial-prompt.zh-CN.md` 与 `photo-abstract-editorial-prompt.en.md`。这意味着即便你没有 Codex 环境，也可以直接把这两份 Prompt 拷出来喂给 Midjourney、DALL·E、Stable Diffusion 等任意图像生成工具复用，迁移成本极低。

## 四、技术亮点与性能数据

这个项目本质是「提示词工程 + 工作流规范」的产物，技术亮点集中在以下四点：

- **约束式 Prompt 设计**：用明确文字禁令 + 结构性描述锁死版面，把 AI 的自由度压缩到「只能调整指定参数」的程度，从而保证产出稳定性。
- **可追溯性原则**：要求每个抽象元素都能反向溯源到原图，这一原则显著降低了「AI 幻觉」造成的画面违和感。
- **参数化抽象自由度**：在「完全放飞」和「完全锁死」之间提供了连续可调的滑点，兼顾了创作品质与效率。
- **生态兼容**：除了 Codex 原生支持，Prompt 本身是模型无关的，可以接入任何支持图像生成或多模态的 LLM，包括 GPT-4V、Gemini、Claude 等。

需要说明的是，该项目不是传统意义上的代码项目，因此没有 QPS、RT 等运行时指标。它的「性能」体现在 Prompt 的稳定性、可复用性与跨平台兼容性上。

## 五、适用场景与人群

**适合谁**：① 内容创作者，需要为小红书、Instagram、Verse、即刻等平台持续输出摄影配文版面；② 视觉设计师，希望快速生成「摄影 + 编辑设计」双层语义的素材；③ 摄影爱好者，想给个人作品集增添编辑设计层次；④ AI 绘画玩家，寻找可复用的、风格稳定的 Prompt 模板。

**不适合谁**：① 只想做传统胶片色调或复古滤镜的用户——这不是滤镜；② 希望把照片改造成插画、动漫、油画的用户——这不是风格迁移；③ 需要对原图进行扩图、修复或重画的场景——这个 Skill 明确禁止改写照片区域。

## 七、如何快速上手

**方式一：作为 Codex Skill 使用**

1. 将整个 `photo-abstract-editorial` 文件夹复制到 Codex 的 skills 目录，例如 `~/.codex/skills/`；
2. 开启新的 Codex 对话，上传一张你想处理的照片；
3. 直接提出需求：「使用 photo-abstract-editorial 将这张照片制作成摄影与抽象面板组合的编辑作品」。

**方式二：作为提示词直接使用**

打开 `references/photo-abstract-editorial-prompt.zh-CN.md` 或英文版，把内容贴到任意图像生成工具中，配合你上传的照片一起提交即可。

**进阶建议**：先用默认参数跑出一版，再针对照片题材微调「抽象程度」参数——风景类建议「关系优先」，地标或主体物建议「保留少量身份特征」。

## 八、总结与行动建议

Photo Abstract Editorial 用一份经过反复打磨的 Prompt，把「摄影 + 抽象编辑版面」这件事变成了一条可复用、可参数化、可追溯的标准化流程。对于内容创作者来说，这意味着：原本一晚上只能出 3 张的版面，现在一杯咖啡的时间就能出十几张，且气质统一。

使用建议：把它当作「编辑设计版的 LUT」——先跑默认参数建立基线认知，再根据自己的审美逐步微调五个维度。

值得一试的理由：4K+ Star 验证、4035 个真实用户的认可、双语完整 Prompt、零代码门槛、跨平台兼容。
