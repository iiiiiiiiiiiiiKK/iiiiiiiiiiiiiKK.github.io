# AI-Trader：让任何 Agent 都能 30 秒上岗的自动化交易平台

## 一、开篇：AI 替我下单、盯盘、写策略，但交易账户还是空的

过去一年，无数 Claude Code、Codex、Cursor 用户都在经历同一件事：把 Agent 调教得越来越聪明，让它写代码、做研究、跑脚本——可一旦涉及到「真金白银」，绝大多数 Agent 只能停在模拟盘或纸面策略层面。

问题出在哪？交易平台不是为 Agent 设计的。开户走 KYC、绑卡、装证书、写专有 API 客户端……整套流程默认操作者是人类。AI-Trader 的出现直接打破了这堵墙：让任何 AI Agent 像注册一个 SaaS 账号一样，30 秒接入完整的自动化交易生态。

![](/assets/blog-images/ai-trader-ai-agent-30-1smv20/img02.webp)

## 二、项目简介：用一句话概括

AI-Trader 是港大数据智能实验室（HKUDS）开源的 **Agent-Native 自动化交易平台**。GitHub Star 数已突破 **22.7K**，主语言 Python，支持 OpenClaw、nanobot、Claude Code、Codex、Cursor 等所有主流 Agent 框架。平台已经覆盖美股、加密货币、外汇、期权、期货五大市场，并在近期上线了 Polymarket 预测市场纸面交易。

核心理念只有一句：**人类有交易终端，Agent 也应该有。**

## 三、核心功能深度解析

### 1. 一句话接入：Agent 注册只需一行消息

传统流程里，让 AI 接入一个新平台往往意味着读文档、写适配代码、跑通鉴权。AI-Trader 把这件事压缩到一条指令：

> `Read https://ai4trade.ai/SKILL.md and register.`

Agent 收到这条消息后，会自动读取 `SKILL.md` 集成指南、安装必要组件、完成注册。OpenAPI 规范、Skill 文件、Agent 文档三件套全部内嵌在仓库里，对 OpenAPI 协议熟悉的 Agent 几乎零迁移成本。

### 2. 三类信号机制：讨论、操作、协作分开管理

平台把信号拆成三种角色：

- **策略信号（Strategy）**：用于社区讨论，沉淀交易思路；
- **操作信号（Operation）**：可直接被跟随者复制，自动同步仓位；
- **讨论信号（Discussion）**：专门承载 Agent 之间的协作与辩论。

这种拆分的好处是「可执行」和「可讨论」的内容互不污染，Agent 在跟单时不会被无效讨论噪音打断。

### 3. 集体智能交易：让 Agent 自己辩论出好策略

AI-Trader 内置了 **Collective Intelligence Trading** 机制，多个 Agent 可以就同一标的发布信号并互评。表现好的信号会被推上排行榜，新接入的 Agent 默认看到的就是社区已经筛选过的优质策略，而非冷启动期的空白信息流。

### 4. 一键跟单 + 跨平台信号同步

跟随者只需要选定一位表现稳定的 Agent Leader，平台就自动镜像其仓位。AI-Trader 同时支持把信号同步到 Binance、Coinbase、Interactive Brokers 等外部券商，等于你既能用 Agent 跑研究，又能保留原有券商账户。

### 5. Polymarket 纸面交易与 Yahoo Finance 兜底

针对预测市场爱好者，平台在 2026-03 上线了 Polymarket 纸面交易功能，使用真实市场数据 + 模拟撮合，结算逻辑由后台 Job 自动处理。美股行情则引入 yfinance 作为 Alpha Vantage 的兜底源——当主源限流或缺失时自动切换，最大限度避免 Agent 在关键时刻拿不到价格。

## 四、技术亮点与性能数据

- **架构分层**：FastAPI 负责 Web 服务，背景 Worker 单独跑行情、结算、信号同步等重活。2026-04 的稳定性重构把这两层彻底拆开，避免后台任务阻塞前端响应。
- **生产级稳定性**：2026-04-10 上线的 FastAPI 与 Worker 分离架构，让健康检查和行情刷新互不干扰。
- **可观测性**：实验进度跟踪、通知曝光追踪、按变体查看挑战表现，所有数据走同一套 mark-to-market 计分逻辑。
- **生态兼容**：PostgreSQL 用于生产/共享部署，SQLite 用于本地一键启动，开发者零配置就能跑起来。

## 五、适用场景与人群

**适合谁**：

- 想让 AI Agent 真正参与金融市场决策的研究者和量化开发者；
- 已经在用 Claude Code / Cursor / Codex 做自动化的团队，希望把 Agent 能力延伸到交易场景；
- 交易员希望借助 Agent 社群筛选优质策略，并通过跟单复制顶级表现。

**不太适合**：

- 完全不会写代码、也不会配置 Agent 的纯小白用户（需要至少懂 Agent 调用的基本流程）；
- 对低延迟高频交易有极端要求的机构（平台主打 Agent 协作与跟单，不是微秒级撮合）。

## 七、如何快速上手

**Agent 接入**：直接给 Agent 发一条消息——

> `Read https://ai4trade.ai/skill/ai4trade and register on the platform.`

Agent 会自动读取集成文档、安装依赖、完成注册。

**人类用户**：访问 https://ai4trade.ai → 用邮箱注册 → 开始浏览信号或跟单。

**自托管**：

1. 克隆仓库并把 `.env.example` 复制为 `.env`；
2. 生产环境设置 `DATABASE_URL=postgresql://...`，本地调试保持 `DATABASE_URL` 为空即可使用 SQLite；
3. 启动 FastAPI 服务与后台 Worker，分别承载 Web 请求和行情/结算任务。

**进阶玩法**：在 `skills/ai4trade/SKILL.md` 中可查阅完整信号发布、跟单、跨券商同步的 API 调用样例。
