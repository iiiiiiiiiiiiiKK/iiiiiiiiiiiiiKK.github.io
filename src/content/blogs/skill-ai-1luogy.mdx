## 一、开篇：你还在为这件事头疼吗？

写完一篇干货文章，配图成了最难的一步。你去 Midjourney 跑一张「未来感科技插画」，结果得到一张氛围感十足却什么都没讲清楚的装饰图；想画一张带数据标注的图表，要么排版丑到没法看，要么中文字直接糊成一团。你想做一张 PKCE 流程图、Kirkpatrick 模型图、Panopticon 隐喻图，冷门概念连参考资料都搜不准。最后只能把一张「漂亮但无用」的图塞进文章，读者扫一眼就划走。

这种「中间那张图」的缺失，正在悄悄毁掉你的内容传播力。

![](/assets/blog-images/skill-ai-1luogy/img02.webp)

## 二、项目定位：它解决的是什么问题

归藏的材质插画 skill（`guizang-material-illustration`）是一个专为 Claude Code / Codex 等 Agent 环境设计的配图 Skill，主打「图内带字、带数据、带标签」。仓库已经获得 997 Stars，是 `guizang-social-card-skill` 的官方配套项目，前者负责卡片内的中心插画，后者负责整张卡片的外层排版。

它专注做三件事：

- **解释图**：把抽象概念、流程、机制、系统关系画成带标签的图。
- **图表美化**：从截图或原始数据里抽取语义，重新生成更适合传播的材质化图表。
- **参考辅助出图**：遇到冷门概念、品牌、模型、科学装置、历史物件时，先查参考信息和参考图，再统一转成归藏材质风格。

## 三、核心功能深度解析

### 1. 图内带字：告别「无字装饰图」

这个 Skill 的核心卖点是「图里真的可以有中文」。多数 AI 配图工具把文字视为累赘，生成出来的图要么纯视觉、要么文字糊成一团。归藏的做法是把短标签、箭头说明、数据标注直接写进生成提示词，让标签在图里就位，不再依赖后期贴字补救。

它配套了一份 `assets/prompt-template.md` 模板，专门教 Agent 怎么稳定写出中文标签。例如画杠杆原理图，会直接标注「支点」「用力点」「阻力点」「力臂」，让小学生也能一眼看懂。

### 2. 图表语义重画：让截图脱胎换骨

输入可以是一张糟糕的图表截图，也可以是一组原始数据。Agent 会先抽取图表类型、标题、横纵轴、单位、类别顺序、数值、百分比、误差线，再重新生成一张更适合传播的图。

关键点是「数据不能编」。它优先保证数值、坐标、单位正确，再谈风格和材质化。最终效果是：图表本体可以更小，旁边可以加入小场景、图标、解释标签和视觉重点，目标是让读者更快看懂，而不是给原图换皮。

### 3. 参考搜索：冷门概念也能画对

画 PKCE、Andon、Zettelkasten、Kirkpatrick、Panopticon、某个模型 Logo、某个科学装置这类内容时，参考搜索只解决三个问题：这个东西是什么、哪些结构不能画错、观众靠什么稳定视觉线索一眼识别它。

它不抄风格，只补事实。查完之后再进入统一的归藏材质插画风格，避免冷门概念画成「看似合理实则错漏百出」的假科普图。

### 4. 多场景适配：从教学到工作汇报全覆盖

支持的图类型相当齐全：概念拆解图、流程图解、循环机制图、对比图、层级架构图、场景解释图、科学机制图、人文意象图、材质化图表（柱状图、折线图、甘特图、桑基图、热力图、漏斗图、累计流图）、参考辅助图。覆盖文章配图、产品机制图、工作汇报、教学材料、人文观点、小红书卡片中心图等具体场景。

## 四、技术亮点与性能数据

`guizang-material-illustration` 的设计亮点集中在「工程化约束」上：

- **标准化视觉规范**：`references/visual-style.md` 定义了归藏材质插画风格、比例、安全区、主题色，默认 IKB 蓝，支持柠檬黄、柠檬绿、安全橙、石墨黑等扩展主题。
- **提示词模式库**：`references/prompt-patterns.md` 沉淀了循环、流程、Hub、对比、层级等提示结构，让 Agent 能稳定复用。
- **QA 优先机制**：`references/qa-checklist.md` 要求交付前检查中文标签、数据、裁切、参考准确性和社交卡片尺寸下的可读性。
- **类型自动路由**：`references/use-cases-and-routing.md` 让 Agent 自动判断是流程图、机制图、图表、人文场景还是教育解释图，不让用户硬选模式。
- **图表语义抽取规范**：`references/chart-beautify.md` 定义了数据优先的重画流程，确保先保数据再谈风格。

生态兼容性上，它原生支持 Claude Code 和 Codex，可通过 `npx skills add` 一行命令安装，也兼容各类具备图像生成能力的 Agent 环境。

## 五、适用场景与人群

**适合谁**：技术博主、产品经理、内容运营、教师学生、研究人员、自媒体创作者。任何需要把抽象概念、流程、数据可视化成「能讲清楚的图」的人。

**不适合谁**：需要完整小红书卡片排版（用 Social Card Skill）、完整 PPT 结构设计（用 PPT Skill）、真实摄影修图、人像写真、长文海报排版、严格出版级数据制图的科研图。

三个典型场景：

- 长文章配图：先拆出 1-4 个核心概念，每个概念生成一张解释图。
- 冷门技术解释：PKCE、Kirkpatrick、Zettelkasten 等抽象概念，先查参考，再做流程图。
- 周报可视化：用进展、风险、决策、下周做四象限或流程配图，告别纯文本汇报。

## 六、竞品对比

| 对比项 | 归藏材质插画 skill | Midjourney / 即梦直接生图 | 通用图表工具（Excel / Flourish） |
|---|---|---|---|
| 图内中文标签 | 原生支持且稳定 | 易糊字、需后期贴字 | 支持但风格单一 |
| 冷门概念参考搜索 | 内置 reference-gathering 流程 | 需自己查 | 不支持 |
| 材质化 3D 风格 | 统一 Swiss editorial + 3D 材质 | 风格随机 | 偏扁平 |
| 图表语义重画 | 抽数据 → 重生成 | 不支持 | 需手动改 |
| 与外层卡片联动 | 可直连 Social Card Skill | 需手动导入 | 需手动导出 |

相比直接用通用生图工具，归藏把「解释图」当成一类专门工件来打磨：标签稳、数据准、参考齐、风格统一。

## 七、如何快速上手

一行命令安装：

```bash
npx skills add https://github.com/op7418/guizang-material-illustration --skill guizang-material-illustration
```

或者直接把安装指令发给 Agent：

> 帮我安装 `guizang-material-illustration`。请把仓库克隆到 `~/.claude/skills/guizang-material-illustration`，安装完成后检查 `SKILL.md`、`assets/`、`references/` 是否存在。

最小可用示例：

> 用歸藏的材质插画 skill，帮我把这段产品说明做成一张带中文标签的机制图。

进阶用法：

- 「把这篇文章挑 3 个核心概念，各生成一张带字配图。」
- 「帮我把这张柱状图重新画成歸藏材质风格，数据和坐标不要改。」
- 「给这篇小学科学课文做一张杠杆原理图，图里标出支点、用力点、阻力点和力臂。」
- 「先生成中心配图，再交给社交媒体卡片 Skill 排成 3:4 小红书卡片。」
