# 一、开篇：从踩坑到真香，只差这一个项目

做威胁情报的同事最近一直在吐槽：他每次跟进一条暗网线索，得先在好几个暗网搜索引擎里手动敲查询，再人工筛掉一堆无关的钓鱼站和镜像，最后再用笔记本整理成报告。一次中等复杂度的调查，耗时 4 到 6 小时，产出还常常遗漏关键节点。更头疼的是，新来的分析师对暗网语法不熟，同样的关键词搜出来的东西质量参差不齐，复现性几乎为零。

OSINT 圈其实不缺工具，但能把「LLM 改写查询 + 结果过滤 + 调查摘要」三件事串成一条完整流水线的开源项目，少之又少。Robin 的出现，正好把这块拼图补上了。

# 二、项目简介：一句话说明它是什么

Robin 是一款 AI 驱动的暗网 OSINT 工具。它借助大语言模型改写查询、过滤暗网搜索引擎返回的结果，并自动生成可读性强的调查报告。当前 GitHub Stars 7.4k+，主仓库语言为 Python，已发布可拉取的 Docker 镜像，并被 GitHub Trending 收录为「当日热门仓库」。

核心关键词：AI 驱动、暗网 OSINT、MCP 协议、多模型兼容、Docker 开箱即用。

# 三、核心功能深度解析

### 1. 多模型无缝切换

Robin 原生支持 OpenAI、Anthropic Claude、Google Gemini、Mistral、OpenRouter、Ollama，以及任何 OpenAI 兼容 API（LM Studio、llama.cpp、Groq 等）。你只要在 `.env` 里填任意一个 `*_API_KEY`，侧边栏就会自动列出可用模型；用 Ollama 也无需配置密钥。Remote 模型自建 / 第三方平台想接的话，侧边栏的「🔌 Custom API Provider」直接填 Base URL 和模型名就行，不用改任何配置文件。这套模型在大多数「某模型今天限流」「想换成本地模型保数据隐私」的真实场景里，省去了大量临时改代码的时间。

### 2. Streamlit Web UI + 对话式追问

工具提供了基于 Streamlit 的交互式 Web 界面，本地启动后访问 `http://localhost:8501` 即可使用。调查结束后，你可以直接对本次结果发起「接地」追问——也就是说，答案只来自本次调查抓取到的数据，不会触发新的暗网搜索。这一点对调查人员尤其重要：既保留了 LLM 的总结能力，又避免了「幻觉」导致的情报污染。

### 3. 一键 Pivot 跳转

Robin 会根据本次发现自动推荐若干后续查询建议，点击即可直接发起新一轮调查。这种「发现 → 推荐 → 再调查」的循环，让分析师不用反复琢磨「下一步该搜什么」，特别适合处理复杂的多跳调查。

### 4. MCP 协议原生支持

Robin 同时提供了 MCP 服务端实现，可以接入 Claude Code、Codex、Claude Desktop、Hermes、OpenClaw 等任何支持 MCP 的 Agent，复用宿主自己的模型。典型的 `claude mcp add` 一行命令就能把它注册进去，相当于让 Claude、Codex 这些 Agent 直接具备暗网 OSINT 能力。

# 四、技术亮点与性能数据

- **Tor 流量隔离**：所有暗网搜索、页面抓取、搜索引擎健康检查都走 Tor，本机应用从不直接请求暗网页面，调查者 IP 不会被泄漏。
- **数据安全处理**：抓取的文本会被放入「untrusted-data」分隔符内，先剥离控制字符、零宽字符、双向控制字符，再交给模型，从而把不可信内容当作「证据」而非「指令」读取，从源头降低提示词注入风险。
- **极简写盘策略**：唯一写入操作是把调查报告落到 `investigations/`，且路径由 Robin 自行命名，Agent 无法指定路径，杜绝任意文件写漏洞。
- **Docker 一键启动**：官方镜像大小合理，`docker run` 一行命令即可拉起；可通过命名卷或本地目录持久化历史调查。
- **生态兼容性强**：同时支持本地（Ollama、llama.cpp）和云端（OpenAI、Claude、Gemini、Mistral、Groq、OpenRouter）模型，适合不同合规要求的团队。

# 七、如何快速上手

**前置条件**：本机已安装 Tor（Linux/WSL：`apt install tor`，macOS：`brew install tor`），并确认 Tor 在后台运行。

**Docker 一键启动（推荐）**：

1. 拉取镜像：`docker pull apurvsg/robin:latest`
2. 创建 `.env` 并填入至少一个 API Key：`touch .env && echo "OPENAI_API_KEY=your_key" >> .env`
3. 启动容器：`docker run --rm -v "$(pwd)/.env:/app/.env" --add-host=host.docker.internal:host-gateway -p 8501:8501 apurvsg/robin:latest`
4. 浏览器打开 `http://localhost:8501`

**进阶建议**：
- 想持久化调查报告，添加 `-v robin-investigations:/app/investigations`。
- 想用本地模型，把 Ollama 的 `OLLAMA_HOST` 设为 `0.0.0.0` 即可，Robin 会自动发现。
- 想把暗网能力接入 Claude/Codex，用官方提供的 `claude mcp add robin -- docker run -i --rm -v robin-investigations:/app/investigations apurvsg/robin mcp` 一行注册即可，并把超时调到 600 秒以上。
