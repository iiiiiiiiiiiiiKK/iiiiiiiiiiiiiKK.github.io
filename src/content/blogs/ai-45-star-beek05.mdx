## 一、开篇：你还在为这件事头疼吗？

做 AI 生图的人，几乎都踩过同一个坑：调色调到怀疑人生。

同一个剧本交给 Midjourney 或 ComfyUI，每次跑出来的色调都不一样——上一组偏青灰，下一组莫名其妙发黄。镜头组同事拿着剧照问「能不能再来一张配色一致的」，你只能苦笑。同样是做「赛博朋克霓虹」，有人出来是《银翼杀手》，有人出来是城乡结合部发光招牌。

问题出在哪？色彩被当成形容词写在 prompt 里，每个模型对「高级灰」「赛博粉」的理解完全不一样。当你需要批量产出风格统一的内容时，这种模糊性就是灾难。

style-pack-skill 这个项目，就是来解决这件事的。

![](/assets/blog-images/ai-45-star-beek05/img02.webp)

## 二、项目简介：用一句话概括

style-pack-skill 是一个 AI Agent Skill，专注于从参考图（电影剧照、视频截图、参考图文件夹）提取可复用的「视觉风格 DNA」，并强制生成标准化色卡，让任何下游生图模型都能锁死色彩一致性。

核心特性四个字概括：「视觉解构 + 色彩固化」。仓库当前 45 Stars，基于 Python 3 + Pillow + NumPy + OpenCV 构建，属于轻量级本地工具。

## 三、核心功能深度解析

### 1. 视觉模块化拆解
项目把参考图按色彩、光影、构图、镜头、材质、节奏六大视觉语法拆分，每个模块独立整理参考图与分组提示词。这意味着你喂给它一组《布达佩斯大饭店》的剧照，它不会傻乎乎地尝试复刻粉色调酒店大堂，而是提取「对称构图 + 奶油粉主色 + 高饱和点缀」的视觉语法，应用到你全新的剧本里。原创场景与原作场景彻底解耦。

### 2. 双重色卡强制生成
这是项目的杀手锏。每完成一个正式视觉分组，自动生成两张 `1920×1080` RGB PNG 色卡：
- **标注色卡**：包含角色编号、中文色名、大写 HEX，方便团队沟通；
- **纯色色卡**：纯 10 个满版色块，零标题、零文字、零留白、零边框——这是喂给 ComfyUI / Stable Diffusion 当 ControlNet 颜色参考用的，模型识别起来最准。

### 3. 固定色彩模型
色彩结构严格锁定为「3 主色 + 5 辅助色 + 2 点缀色 = 10 色」。这套比例来自实战经验：主色定基调，辅助色铺层次，点缀色抓眼球。10 个色块既能覆盖复杂场景，又不会让模型「选择困难」。

### 4. 自动化验收
提供 `generate_palette_cards.py` 生成器与 `validate_palette_cards.py` 验收器，后者会逐张检查——缺任意一张色卡直接判定失败。这把「忘了导出纯色版」这种低级错误彻底焊死。

## 四、技术亮点与性能数据

| 维度 | 实现方式 |
|------|----------|
| 图像处理 | OpenCV 提取主色，K-Means 聚类从像素空间收敛到目标色数 |
| 色卡生成 | Pillow 绘制，纯色版强制去除所有装饰元素 |
| 规格严格 | 1920×1080 RGB PNG，固定尺寸喂 ComfyUI 不会出现拉伸 |
| 验收 | 自动化脚本检查文件存在性 + 像素纯色验证（OpenCV 读图后判断是否纯色块） |
| 输出物 | 双色卡 PNG ×2 + 总览图 + 结构化 JSON（含 HEX、HSL、中文色名） |

整个色卡生成流程在本地秒级完成，不依赖任何外部 API，无网络成本。

## 五、适用场景与人群

**适合的人**：
- AI 生图工作流从业者（ComfyUI / SD WebUI / Midjourney 重度用户）；
- 短剧 / 漫剧 / 有声书平台的视觉负责人，需要批量产出风格统一物料；
- 影视、广告、品牌设计团队，要做视觉风格指南但不想从零调色；
- 个人创作者维护自己的「视觉风格库」。

**不适合的人**：
- 只做单张图、不需要风格复用的人——直接调 prompt 更划算；
- 需要人物 / 物体内容复刻的人——本项目刻意回避场景与元素复用；
- 纯前端 / 后端开发者——这是视觉工作流工具。

## 六、竞品对比

| 工具 | 色彩固化 | 自动验收 | 纯色版色卡 | 本地运行 | 风格库复用 |
|------|----------|----------|------------|----------|------------|
| Midjourney `--sref` | 模糊 | ❌ | ❌ | ❌ | ✅ |
| ComfyUI IP-Adapter | 中等 | ❌ | ❌ | ✅ | ⚠️ 依赖参考图 |
| 色卡提取网站 | 仅提取 | ❌ | 部分 | 部分 | ❌ |
| **style-pack-skill** | **精确到 HEX** | **✅** | **✅ 强制** | **✅** | **✅** |

关键差别：其他工具要么「提取但不固化」（色卡网站），要么「固化但不标准化」（Midjourney），style-pack-skill 是少数把「提取 + 固化 + 验收」三件事一步走完的开源方案。

## 七、如何快速上手

**Step 1：克隆到 Agent Skills 目录**

```bash
git clone <仓库地址> 风格包
```

确保 `SKILL.md` 位于技能根目录。

**Step 2：安装依赖**

```bash
pip install Pillow NumPy OpenCV-Python
```

**Step 3：喂参考图，跑色彩提取**

把电影剧照 / 视频截图放进项目目录，交给 Agent 按 `references/提取风格包.md` 工作流处理。

**Step 4：生成 + 验收色卡**

```bash
python3 scripts/generate_palette_cards.py "<风格包目录>" --title "<项目名称>"
python3 scripts/validate_palette_cards.py "<风格包目录>"
```

第二条命令不通过，就别往下走 ComfyUI——必跑。

**进阶建议**：把生成好的纯色色卡塞进 ComfyUI 的「Load Image」节点，接 ControlNet 的颜色参考，做风格锁定的批量出图。

## 八、总结与行动建议

style-pack-skill 解决的是 AI 生图里最隐蔽也最浪费时间的痛点：**色彩不一致**。通过视觉模块解构 + 强制双版色卡 + 自动验收三件套，让「风格复用」从玄学变成可执行 SOP。

如果你正在被「每张图色调都不一样」折磨，强烈建议把这个 Skill 装进 Agent。它不大、不重，但能让下游所有生图节点都接到同一套色彩 DNA。
