## 一、开篇：为什么你需要这个工具？

写中文长文的人都懂这个痛点：文章写完了，配图环节卡住了。

打开 Midjourney 或 GPT-4o 输入 prompt，出来的图要么是 PPT 风格的信息图，要么是精致到毫无个性的扁平插画，要么就是一只莫名其妙的吉祥物站在角落微笑。

更糟的是，你想要的不是「一张好看的图」，而是「把文章里那个核心判断画出来」——比如「信任是一块证据一块证据铺过去的」这种认知动作。AI 听不懂，设计师听不懂，最后你只能放一张毫无信息增量的风景图撑场面。

GitHub 上 9.3K Stars 的 `helloianneo/ian-xiaohei-illustrations` 专门解决这个问题：它不是一个 prompt 集合，而是一套给 Codex Agent 用的 Skill，专门把中文文章里的判断、流程、状态和隐喻，变成白底手绘、怪诞但清爽的正文配图。

![](/assets/blog-images/post-1f6w5m/img02.webp)

## 二、项目简介：一句话说明它是什么

`ian-xiaohei-illustrations` 是一个 Codex Skill，用来指导 AI Agent 为中文文章生成「小黑怪诞正文配图」。

核心特性有四个：

- **16:9 白底手绘风**：纯白背景、黑色手绘线稿、细线轻微抖动，区别于 PPT 信息图和商业插画。
- **小黑 IP 承载动作**：默认视觉 IP「小黑」是黑色实心、白点眼、细腿、空表情的小角色，承担画面里的核心认知动作，不是装饰。
- **少量红橙蓝中文批注**：手写批注极简，颜色克制，整张图只表达一个核心结构。
- **Shot list 先于图像**：Skill 流程强制先输出 4-8 张图的规划清单（主题、核心意思、结构类型、小黑动作），再生成图片。

项目累计 9359 Stars，配套作者 Ian 的同系列 `ian-handdrawn-ppt`、`obsidian-ai-second-brain`，构成一套完整的 AI 一人公司内容生产工具链。

## 三、核心功能深度解析

### 1. 认知锚点提炼

Skill 第一步是「读文章、找锚点」。它强制 AI 从原文里挑出真正值得配图的段落——通常是认知转折、流程结构、状态对比或可视觉化的隐喻。这套机制避免了「为配图而配图」的无效产出。

### 2. Shot List 先行

在生图之前，Skill 要求 AI 输出一个完整的 shot list：每张图放在哪段后、主题是什么、核心意思、结构类型（Workflow / 系统局部 / 前后对比 / 角色状态 / 概念隐喻等 8 种）、小黑在做什么、建议的中文标注词。这一步把「盲盒式出图」变成「按剧本排片」。

### 3. 物理隐喻重发明

Skill 要求 AI 为每张图重新发明一个低科技、怪诞但成立的物理隐喻，而不是套用旧案例。例如「一鱼多吃」「想法压机」「信息井」「信任桥」这些示例图，每张都是一个独立的小隐喻系统。这种约束让画面有记忆点，且与文章内容强绑定。

### 4. 小黑必须承担核心动作

这是 Skill 里最硬核的一条规则：「如果去掉小黑画面仍然完全成立，说明小黑太装饰了。」这条 QA 规则保证了小黑 IP 不是吉祥物贴纸，而是正在参与系统运转的荒诞工作者。

![](/assets/blog-images/post-1f6w5m/img03.webp)

### 5. 非 PPT 风格约束

Skill 明确禁止的输出包括：PPTX / PDF / Keynote、SVG / HTML 可编辑图、商业海报封面、长段文字型信息图。它要的不是「万能图」，而是「文章专属图」。

### 6. 编辑与重生成工作流

针对 AI 图像常见的错字、幻觉标签、风格漂移问题，Skill 提供了「去掉标题」「减少标注词」「按段落重生成」等细粒度编辑指令，让用户不用推翻整张图就能迭代。

## 四、技术亮点与性能数据

- **风格 DNA 模块化**：`references/style-dna.md`、`xiaohei-ip.md`、`composition-patterns.md`、`prompt-template.md`、`qa-checklist.md` 五份参考文档，把视觉规则拆成可独立维护的模块，新增风格或调整留白比例时改一个文件即可。
- **8 种构图模式**：Workflow、系统局部、前后对比、角色状态、概念隐喻、方法分层、地图路线、小漫画分镜，覆盖技术文章和方法论文章 90% 的可视化需求。
- **OpenAI Agent 兼容**：仓库内置 `agents/openai.yaml`，可直接被 Codex / 兼容 Agent 框架加载，无需额外封装。
- **MIT 协议开源**：可自由商用、修改、二次分发，配合同作者的 `Awesome Claude Code Skills` 形成生态。
- **QA Checklist 内建**：白底、留白、小黑动作、中文标注、非 PPT 感、非旧案例复刻——六项自动校验标准写在 `qa-checklist.md` 里，每张图生成后逐项过检。

## 五、适用场景与人群

**特别适合**：

1. **知识型公众号 / 博客作者**：写中文长文，需要 4-8 张统一风格的正文配图，且配图必须传递认知增量。
2. **方法论内容创作者**：做 AI 工作流、Indie Maker、内容生产方法论的人，需要把抽象判断画成视觉隐喻。
3. **Notion / Obsidian 知识库用户**：用 AI 整理个人知识库时，希望文档里的图都有统一的视觉语言。

**不适合**：

1. 需要商业海报、品牌 KV、精致扁平插画的设计需求。
2. 需要可编辑矢量源文件（SVG/AI）的印刷物料。
3. 需要儿童卡通、可爱 IP、表情包风格的内容。

|-----|------|---------|---------|---------------|

## 七、如何快速上手

### 安装

克隆仓库并把 skill 子目录复制到 Codex skills 目录：

```bash
git clone https://github.com/helloianneo/ian-xiaohei-illustrations.git
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R ./ian-xiaohei-illustrations/ian-xiaohei-illustrations "${CODEX_HOME:-$HOME/.codex}/skills/"
```

### 最小可用示例

在 Codex 里贴入：

```text
Use $ian-xiaohei-illustrations 为这篇中文文章设计并生成 5 张小黑怪诞正文配图。
```

如果只想先规划不生图：

```text
Use $ian-xiaohei-illustrations 先不要生图。
请分析下面这篇文章哪里值得配图，输出 5 张左右的 shot list。
```

### 进阶建议

- 中文批注控制在 2-6 字，错字率最低。
- 遇到严重错字时，先「去掉错误文字」局部编辑，再减少标注词重生成。
- 不要复刻 `examples/images/` 里的构图，示例图只用于风格校准。
