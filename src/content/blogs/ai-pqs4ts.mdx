## 一、开篇：写小说的人，最怕什么？

凌晨截稿前两小时，第 47 章写到一半，网页突然崩溃——三千字没保存。

更让人头疼的是：作品丢在某个在线平台的服务器里，你想换平台、想本地留档、想把数据迁出来，对不起，平台说不行就是不行。AI 续写要用？行，先充会员。换个 DeepSeek 模型试试？抱歉，没接口。

写作者对「工具」的诉求其实很朴素：稿子得稳、得在自己手里、AI 想换谁就换谁。

今天要聊的「易创 easy-writing」就是冲着这几点来的——一个 GitHub 上 692 Stars、纯本地、开源的网文写作桌面软件。

## 二、项目简介：把稿子握在自己手里的桌面写作软件

「易创」定位很清晰：**纯本地的网文写作桌面软件**，主打小说创作、AI 辅助写作、BYOK（自带 Key）与自定义提示词。

几个关键标签：

- **纯本地**：作品、设定、写作记录全部存本机（SQLite 数据库文件）
- **BYOK**：DeepSeek、通义千问、智谱、Kimi、OpenAI 等都能配，API Key 留本机，请求直连服务商
- **开源免费**：AGPL-3.0 协议，代码全公开
- **真人打磨**：由长期运营的写作平台客户端改造而来，编辑器、自动保存、章节管理都经过真实网文作者日常使用

适合起点、番茄、七猫、晋江等平台的作者，也适合任何想把稿子攥在自己手里的写作者。

## 三、核心功能深度解析

### 1. 写作台：稳到「异常崩溃都帮你恢复」

写作台基于 TipTap 富文本编辑器，配上卷/章目录树、拖拽排序、全书搜索、查找替换。

稳，是它的最大卖点：

- **160ms 本地落盘** + 关窗快照，异常退出重开即恢复
- **每章自动保留历史版本**，随时回看与恢复
- **敏感词检测**（本地词库可自定义）、打字音效、专注模式、自爆挑战

另外，参考资料五件套——大纲、角色（含关系图画布）、设定、时间线、故事线（思维导图画布）——全在本地，写作时随调随用。

### 2. 沉浸式写作体验：从按键音到光标特效

写网文是个「氛围活」，易创在这点上做得相当细致：

- **按键音效**：青轴机械键、茶轴机械键、老式打字机、枪声、狗狗汪叫……不喜欢可以完全静音
- **光标视觉特效**：每次输入可触发挥毫泼墨、墨纹涟漪、云烟缭绕、真实烈焰或文字鼓励，一键关闭
- **编辑器自由排版**：字体、粗细、颜色、字号、行高、正文宽度、段间空行、对齐方式、网格线样式都能调
- **四套主题 + 8 张背景图**：无界通透、古韵信笺、森系护眼、暗夜水墨，也支持自定义背景图

还内置**专注与阅读预览**：全屏写作、停止输入倒计时的「自爆挑战」、与正文同步滚动的手机阅读预览——这些功能基本是盯准网文作者日常痛点设计的。

![](/assets/blog-images/ai-pqs4ts/img04.webp)

### 3. AI 辅助：BYOK + 提示词全开放

AI 这块是易创的重头戏，核心思路：**你的 Key、你的提示词、你的模型**。

- **划词 AI 工具**：选中文字一键润色/扩写/纠错/自定义指令，改完可采纳可废弃
- **续写补全**：快捷键整拍续写（流式进正文）+ 打字时的幽灵字建议（Tab 采纳）
- **妙笔对话**：右栏 AI 顾问，剧情/人设/设定随时聊，会话历史本地保存
- **工作流一键建书**：灵感 → 大纲 → 设定 → 建书 → 逐章自动生文，断点可续
- **竞品拆书**：TXT 整本导入，逐章拆解节奏与卖点，黄金三章深析 + 全书报告
- **AI 调用账本**：每次调用的场景、字数、Token、成败原因全记录

特别值得一提的是**提示词全开放**：所有 AI 提示词都是本机的 md 文件，界面里可视化改，或者直接改文件，连每个场景的采样温度都能调。想自己写一套提示词？直接编辑文件就行。

本地部署的 Ollama、LM Studio 等模型也支持——API Key 留空即可。

### 4. 榜单风向：用自己的网络抓数据

内置爬虫抓起点、番茄、七猫等 80+ 排行榜源，数据只存本机。趋势分析、标签风向、CSV 导出、AI 解读一应俱全。

注意：抓取行为发生在用户自己的设备与网络上，请遵守目标网站的服务条款，控制抓取频率。

## 四、技术亮点与性能数据

- **技术栈**：Vue 3 + TypeScript + Vite + Pinia + Element Plus + TipTap 3 + Tauri 2
- **数据存储**：应用数据目录下的 SQLite 数据库；自动备份默认在「文稿」目录（txt+json）
- **160ms 本地落盘**：写一句话，160ms 内写入本地数据库
- **桌面端打包**：Tauri 2 构建，体积远小于 Electron 同类应用
- **版本自动检测**：每天最多一次，只查 GitHub 公开接口
- **AGPL-3.0 协议**：可自由使用、修改、分发，修改版本必须同样开源

## 七、如何快速上手

1. **下载安装**：到 [Releases](https://github.com/yilujian/easy-writing/releases) 页面下载对应系统的安装包（macOS 选 `.dmg`，Windows 选 `.exe`）
2. **首次打开**：点「新建作品」写书名建书，直接开写——**写作功能不需要任何配置**
3. **配置 AI**：侧栏「模型管理」→ 选服务商预设（如 DeepSeek）→ 填入你自己的 API Key → 测试连接 → 保存，再设为默认模型
4. **自定义提示词**：侧栏「提示词管理」里每个场景都能改，恢复默认随时可点
5. **迁移数据**：换电脑时，书架里整本导出 JSON（含参考资料），新电脑导入即可；或直接拷贝应用数据目录

**开发命令**（给想折腾的开发者）：

```bash
pnpm install
pnpm dev        # 浏览器开发模式（端口 6789）
pnpm tauri build # 打包桌面端
```
